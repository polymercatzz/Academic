# Before-you-present audit

Run on every slide. Every "no" is a fix. Report results per slide.

## Strongest tells

- [ ] Slide starts with its title; nothing above it (eyebrow, kicker, breadcrumb, pill).
- [ ] Zero slips: no overlap, overflow, placeholder text, split words (check Thai line ends), title numbers match the slide and the report.
- [ ] Sentences sound spoken; no colon-title or em-dash-pivot habit.
- [ ] No takeaway box, no filled bottom banner.
- [ ] No full-height colored edge strip.

## Some signal

- [ ] Lists have as many items as the content needs, not threes by habit.
- [ ] No buzzwords (English list in tells.md #4, Thai list in SKILL.md).
- [ ] Body text left-aligned; centering only for single short items.
- [ ] No inflated significance; each slide says what happened and how big.

## Weak signal

- [ ] Title is a full-sentence takeaway; titles alone tell the argument.
- [ ] One point per slide; one element clearly wins; title much bigger than body.
- [ ] Every number has a nameable source; zero invented stats, quotes, examples.
- [ ] No emoji, icons in circles, decorative icons, stock 3D or unrelated images.
- [ ] No purple glow, glassmorphism, gradient text; palette chosen on purpose, not cream-terracotta or dark-navy default.
- [ ] One accent color, used only on the key point.
- [ ] Specific nouns (names, numbers, dates, places) on most slides.
- [ ] Layouts vary with content; no symmetric three-box grids; no single repeated template.
- [ ] Bullet lists short, uneven, rare.
- [ ] Each chart/diagram has a takeaway title and an annotation on the key point.
- [ ] No "experts say" / "studies show" without a named source.
- [ ] No "not just X, it's Y" lines.
- [ ] No rounded boxes/cards with a colored accent edge; no drop shadows, floating cards, cards in cards.
- [ ] No accent bar above/beside/under the title.
- [ ] Cover subtitle is a few words or absent.
- [ ] One typeface, regular + bold, 3–4 sizes used consistently.
- [ ] No pills, badges, chips, status dots.
- [ ] No row of equal stat tiles.
- [ ] Deck ends on the decision or ask, not a future-prospects wrap-up.
