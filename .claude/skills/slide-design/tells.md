# The 31 tells and their fixes

Signal = how well the tell separated 94 AI slides from 100 real consulting slides in the guide's comparison (AI % vs real %). **Strong** tells give a deck away on their own; fix those first. Weak tells are still worth fixing. One instance on one slide is a choice; the same one on every slide is a tell.

## Strong signal (fix first)

| # | Tell | Fix |
|---|---|---|
| 19 | Anything above the title: ALL-CAPS eyebrow, kicker, breadcrumb, pill (46 vs 8) | Start with the title. Section markers, if truly needed, are built once into the template, small, sentence case, same spot. |
| 29 | Production slips: overlap, overflow, placeholders ("Click to add", "xxx", "Series 1"), split words, title numbers ≠ slide (30 vs 7) | Inspect every slide at full size; list placeholders; cross-check numbers. |
| 12 | Same-shape sentences: colon titles, em-dash pivots, uniform length (40 vs 19) | Write as you'd say it. Short. Some shorter. Active voice. |
| 30 | "Key takeaway" / "So what" box or filled bottom banner (18 vs 3) | Takeaway goes in the title; any extra so-what line is plain body text. |
| 31 | Full-height colored strip down the left/right edge (17 vs 1) | Leave the edge alone. |

## Some signal

| # | Tell | Fix |
|---|---|---|
| 4 | Buzzwords: unlock, elevate, delve, dive in, leverage, empower, harness, seamless, robust, game-changer, cutting-edge, transformative, synergy, journey, "in today's fast-paced world", "let's explore" (15 vs 8) | Specific nouns, plain verbs: name the thing, the number, the date. |
| 9 | Centered everything (6 vs 0) | Left-align body; center only one big number, a one-line quote, a section break. |
| 13 | Inflated significance: "pivotal", "a testament to", "plays a crucial role", "broader trend" (3 vs 0) | State what happened and how big it was. |
| 17 | Groups of three by habit (21 vs 11) | Use as many items as exist; cut the vague filler item. |

## Weak signal (real decks do it too — still fix)

| # | Tell | Fix |
|---|---|---|
| 1 | Generic label titles ("Overview", "Next Steps") | Full-sentence takeaway title; titles alone tell the argument. |
| 2 | Emoji bullets, icons in circles that repeat the word | Use the space for a chart, screenshot, real photo, or nothing. |
| 3 | Purple glow gradients, glassmorphism, gradient text | One background, one text color, one gray, one accent; flat fills. |
| 5 | Symmetric three-icon/three-box grid | Asymmetric layout that follows content: one big + two small; chart ⅔ + note. |
| 6 | Stock 3D blobs, glowing brains, unrelated hero images | Show the real object (screenshot, chart, place) or no image. |
| 7 | Uniform bullet walls, bold-lead-in-colon on every bullet | One idea per slide; vary rhythm: quiet, dense, quiet. |
| 8 | Fake or unsourced stats | Every number has a nameable source; else `[DATA NEEDED: …]`. |
| 10 | Same layout on every slide | Rotate a few layouts (statement, chart, comparison) by purpose; consistency comes from type, color, margins. |
| 11 | Chart junk: 3D pies, far legends, all gridlines, fake cycle/funnel diagrams | Takeaway title → chart → annotation on the point; gray context, accent on the point; diagrams only for real processes. |
| 14 | Vague attribution ("experts say", "studies show") | Name source + date, or `[SOURCE NEEDED: …]`, or cut. |
| 15 | Tidy "Challenges and Future Prospects" ending | End on the decision or ask; risks sit beside the decision they affect. |
| 16 | "It's not just X, it's Y" / "Not only X, but Y" | Delete the setup; say Y specifically. |
| 18 | Rounded boxes with a colored accent edge, repeated | No accent-edged boxes. Separate with whitespace/alignment; a thin gray rule or square plain area if grouping is real. Test: delete the box — still clear? |
| 20 | Short thick accent bar above/under the title | Leave it out; size, weight, position already lead the eye. |
| 21 | Full-sentence subtitle on the cover | A few words (audience, event, date) or none. |
| 22 | Everything the same weight | Pick what the eye lands on first; make it bigger, heavier, more alone. |
| 23 | Default type chaos, or italic-serif / recolored last words in titles | One typeface, regular + bold, 3–4 sizes used consistently; emphasize with bold *or* color, never both. |
| 24 | Floating cards, drop shadows, cards in cards | Flat. Tables are plain with thin horizontal lines. |
| 25 | Accent color everywhere | Accent only on the one thing that matters on that slide; otherwise gray. |
| 26 | The new default palettes: cream + serif + terracotta; dark navy/black + one bright accent; dark blue-to-orange | Choose the palette on purpose (brand, or a stated 3–4 color set) and tell the user what you chose. |
| 27 | Pills, badges, chips, status dots | Write the word in the cell or sentence, or cut it. |
| 28 | Row of equal dashboard stat tiles | Title says what the numbers prove; show the one proving number large or as a chart; rest in a table or appendix. |
