## 1. การใช้ภาษาและการอ้างอิง

- ใช้ภาษาวิชาการ กระชับ ได้ใจความ หัวข้อต่อเนื่องกัน
- คำศัพท์ใช้ตามศัพท์บัญญัติราชบัณฑิตยสถาน — ตรวจที่ <https://www.orst.go.th/>
- ข้อมูลจากแหล่งอื่น ทำได้ 2 วิธี
  1. เรียบเรียงด้วยสำนวนตนเอง **และ** อ้างอิงแหล่งที่มา
  2. คัดลอกตรง ๆ ต้องใส่อัญประกาศ “ ” **และ** อ้างอิง — รวมกันได้ **ไม่เกิน 15%** ของข้อความทั้งเล่ม
- ⚠️ ถ้ากรรมการพบการคัดลอกที่ไม่ตรงข้อกำหนด **ได้ F ทันที**
- การอ้างอิงในเนื้อหาใช้ระบบตัวเลข `[1]` วางท้ายข้อความที่อ้าง เช่น "…เป็นส่วนสำคัญ [1]" (4.11)

## 6. ตาราง รูป และเครื่องหมายวรรคตอน (4.6–4.9)

**ตาราง**
- วางในบทที่เกี่ยวข้อง
- **"ตารางที่ X.Y" ตัวหนา ชิดซ้าย อยู่เหนือตาราง** ตามด้วยชื่อตารางตัวปกติ
- ชื่อยาวเกิน 1 บรรทัด → บรรทัดถัดไปเริ่มตรงกับอักษรตัวแรกของชื่อตาราง
- ไม่เว้นบรรทัดระหว่างชื่อกับตาราง; จบตารางเว้น 1 บรรทัด
- ตารางข้ามหน้า → หน้าใหม่พิมพ์ "ตารางที่ X.Y (ต่อ)" + ชื่อตาราง
- เลขเรียงตามบท: บท 1 → 1.1, 1.2; บท 2 → 2.1, 2.2; ภาคผนวกใช้ ก.1, ก.2

**รูป**
- เว้น 1 บรรทัดก่อนรูป วางรูป **กึ่งกลาง**
- **"รูปที่ X.Y" ตัวหนา + คำบรรยาย อยู่ใต้รูป กึ่งกลาง**; คำบรรยายยาวเกินบรรทัดให้บรรทัดล่างตรงกับอักษรตัวแรก
- เว้น 1 บรรทัดหลังคำบรรยาย
- เลขเรียงตามบทเหมือนตาราง

**เว้นวรรคหลังเครื่องหมาย**

| เครื่องหมาย | เว้น |
|---|---|
| มหัพภาค `.` | 2 ช่วงอักษร |
| จุลภาค `,` อัฒภาค `;` มหัพภาคคู่ `:` อัญประกาศ `“ ”` | 1 ช่วงอักษร |

## 7. บรรณานุกรม (4.10)

- คำว่า "บรรณานุกรม" 24 หนา กึ่งกลาง
- ลำดับ `[1]` ชิดซ้าย **เรียงตามลำดับที่อ้างถึงในเนื้อหา** (ไม่ใช่ตามตัวอักษร)
- บรรทัดที่ 2 ของรายการ เว้น 7 ตัวอักษร เริ่มที่อักษรตัวที่ 8
- ชื่อหนังสือ 16 หนา; ปี พ.ศ. ที่พิมพ์อยู่ท้าย
- "บรรณานุกรม" = เอกสารที่ค้นคว้าทั้งหมด แม้ไม่ได้คัดลอก

รูปแบบ (`/` = เว้น 1 ช่วง)

| ประเภท | รูปแบบ |
|---|---|
| หนังสือ | `ผู้แต่ง.//ชื่อหนังสือ.//ครั้งที่พิมพ์.(ถ้ามี)//เมืองที่พิมพ์/://สำนักพิมพ์.//ปีที่พิมพ์` |
| บทความวารสาร/ประชุม | `ผู้แต่ง.//“ชื่อบทความ”//ชื่อวารสาร.//ปีที่,/ฉบับที่./เดือน ปี.//หน้า/เลขหน้า-เลขหน้า.` |
| วิทยานิพนธ์ | `ผู้แต่ง.//“ชื่อวิทยานิพนธ์”//ชื่อปริญญา (เต็ม).//ปีที่พิมพ์.` |
| สิทธิบัตร | `ผู้จดสิทธิบัตร.//ชื่อสิ่งประดิษฐ์.//ประเทศ.//หมายเลข.//วัน เดือน ปี.` |
| โสตวัสดุ | `ผู้จัดทำ.//“ชื่อเรื่อง.”//[ชนิดสื่อ].//สถานที่ผลิต/://ปี.` |
| **เว็บไซต์ / ออนไลน์** | `ผู้แต่ง.//“ชื่อเรื่อง.”//[Online].//เข้าถึงได้จาก/://URL.//ปีที่เผยแพร่ (หรือสืบค้น)` |

ตัวอย่างออนไลน์ (สำหรับเล่มนี้ เช่น SchoolBright, เอกสาร FastAPI)

```
[1] SchoolBright. “<ชื่อหน้าเว็บที่อ้าง>.” [Online]. เข้าถึงได้จาก : <URL>  2569
```

## 8. ประวัติผู้เขียน (4.3.1)

คนละ 1 ช่อง ติดรูป: คำนำหน้าชื่อ + ชื่อ-นามสกุล, รหัสนักศึกษา, วัน เดือน ปีเกิด และสถานที่เกิด, ประวัติการศึกษา (วุฒิ ม.6 / สถาบัน), ภูมิลำเนา, เบอร์โทร, E-mail, สาขาที่จบ รุ่นที่ ปีการศึกษา, ประวัติการทำงาน (ถ้ามี)
