# ปัญหาในระบบเดิม

สรุปจากผล Pain Point Analysis ที่ทีมทำไว้กับหน้าจอของระบบเดิม 17 หน้า ใช้เป็นที่มาของหัวข้อ "ปัญหาในระบบเดิม" ใน [personas.md](personas.md)

> **ที่มาของข้อมูล:** ผลวิเคราะห์นี้มาจากการที่ทีมไล่ใช้หน้าจอของระบบเดิมเอง ยังไม่ใช่ผลสัมภาษณ์ผู้ใช้ "ผลกระทบ" ในแต่ละข้อจึงเป็นการคาดการณ์ของทีม ถ้าได้สัมภาษณ์ครูหรืองานวิชาการ ควรเติมคำพูดจริงหรือความถี่ของปัญหาไว้ในตารางด้านล่าง
>
> **ขอบเขต:** มีข้อมูลเกือบทั้งหมดในฝั่งงานวิชาการ (admin) ฝั่งครูมีแค่หน้าตรวจสอบการเช็กชื่อ ส่วนงานกรอกคะแนน เวลาไม่ว่าง และคำร้องขอเปลี่ยนตาราง ยังไม่มีผลวิเคราะห์

## ปัญหาที่ซ้ำกันหลายหน้า

| # | ปัญหา | พบใน | แนวทางที่ทีมเสนอ |
|---|---|---|---|
| P1 | **ต้องเลือกตัวกรองใหม่ทุกครั้งก่อนเห็นข้อมูล** แม้ส่วนใหญ่จะดูปีการศึกษาและภาคเรียนปัจจุบัน | 8 หน้า: การเข้าเรียน, ผู้ไม่มีสิทธิ์สอบ, สอบซ่อมรายห้อง, ลำดับคะแนน, ข้อมูลรายวิชา, ตรวจสอบการเช็กชื่อ, ผลสัมฤทธิ์, ประเมินพัฒนาผู้เรียน | ค่าเริ่มต้นเป็นปีและภาคปัจจุบัน จำค่าที่ค้นล่าสุด และแสดงข้อมูลทันทีเมื่อเข้าหน้า |
| P2 | **ตัวกรองไม่ครบหรือไม่สัมพันธ์กัน** ขาดตัวกรองที่ใช้จริง (ห้อง ครูผู้สอน แผนการเรียน สถานะนักเรียน รหัสหรือชื่อนักเรียน) และ dropdown แต่ละตัวไม่กรองตามกัน | 8 หน้า: ผู้ไม่มีสิทธิ์สอบ, ทะเบียนสะสม, คะแนนเฉลี่ย, ผลการเรียนรายวิชา, ไม่ผ่านเกณฑ์, สอบซ่อมรายวิชา, สอบซ่อมรายห้อง, ข้อมูลรายวิชา | เพิ่มตัวกรองที่จำเป็น ใช้ Cascading Dropdown (ปี → ภาค → ชั้น → ห้อง → วิชา) ซ่อนตัวกรองที่ใช้น้อยไว้ใน Advanced Filter |
| P3 | **ตารางผลลัพธ์ค้นหา เรียง หรือกรองไม่ได้ และไม่มีสรุปภาพรวม** อยากเปลี่ยนมุมมองต้องค้นหาใหม่ ต้องไล่ตัวเลขเองว่าตรงไหนผิดปกติ | 8 หน้า: คะแนนเฉลี่ย, ผลการเรียนรายวิชา, สอบซ่อมรายวิชา, สอบซ่อมรายห้อง, ข้อมูลรายวิชา, ตรวจสอบการเช็กชื่อ, ผลสัมฤทธิ์, ประเมินพัฒนาผู้เรียน | Search / Sort / Filter ในตาราง และ Summary ก่อนตาราง (จำนวน ค่าเฉลี่ย ร้อยละ จุดที่ควรตรวจสอบ) |
| P4 | **ดูรายละเอียดหรือแก้ไขต้องออกไปหน้าอื่น** แล้วค้นหาซ้ำเมื่อกลับมา | 5 หน้า: การเข้าเรียน (แก้สถานะอยู่คนละหน้า), ไม่ผ่านเกณฑ์, จัดตารางเรียน, โครงสร้างหลักสูตร, ประเมินพัฒนาผู้เรียน | Drill-down หรือ Expand / Collapse ในหน้าเดิม และเปลี่ยนห้อง ชั้น หรือภาคได้จากหน้าที่อยู่ |
| P5 | **ส่งออกไฟล์แล้วต้องจัดรูปแบบต่อ** ได้แค่ Excel หรือแค่ PDF, Excel แยกหนึ่ง sheet ต่อหนึ่งวิชา, เมนูส่งออกแยกย่อยกว่า 6 แบบ | 5 หน้า: การเข้าเรียน, ผู้ไม่มีสิทธิ์สอบ, ผลการเรียน, ทะเบียนสะสม, ลำดับคะแนน | ส่งออกได้ทั้ง Excel และ PDF, Excel เป็นตารางเดียวแบบ flat มีคอลัมน์ชื่อวิชา, รวมเป็นปุ่มเดียวแล้วเลือกคอลัมน์ |
| P6 | **ไม่มี Preview หรือ Preview ต้องสร้างสองรอบ** | 2 หน้า: ทะเบียนสะสม, ผลการเรียน (เลือกภาษาหลังสร้าง Preview แล้ว) | Preview ก่อนส่งออก และตั้งค่าทั้งหมดรวมถึงภาษาก่อนกดสร้าง |
| P7 | **คำสั่งหลักซ่อนอยู่ใน dropdown หรือ UI ไม่สม่ำเสมอ** | 3 หน้า: ข้อมูลรายวิชา ("เพิ่มวิชา" อยู่เมนูเดียวกับ Export), โครงสร้างหลักสูตร, ลำดับคะแนน (วิชาที่ยังไม่มีคะแนนแสดงข้อความแทนปุ่ม) | แยกคำสั่งหลักเป็นปุ่ม ตั้งชื่อปุ่มตามงาน ปุ่มที่ใช้ไม่ได้ให้เป็น disabled แทนการหายไป |
| P8 | **ไม่รู้ว่าข้อมูลมีกี่รายการและอัปเดตล่าสุดเมื่อไร** | 1 หน้า: ข้อมูลรายวิชา | แสดง "พบ 12 รายวิชา" และเวลาแก้ไขล่าสุด |
| P9 | **ต้องเลื่อนหรือ hover จึงเห็นข้อมูลครบ** แสดงได้ 13 วิชาต่อหน้า, รายละเอียดคาบเห็นแค่ตอน hover (ใช้บนจอสัมผัสไม่ได้), ตารางรายเดือนยาวมาก | 3 หน้า: ผลการเรียน, จัดตารางเรียน, ตรวจสอบการเช็กชื่อ | เลื่อนลงแทนการแบ่งหน้า ช่องตารางแสดงข้อมูลสำคัญถาวรและคลิกเพื่อเปิดรายละเอียด จัดกลุ่มตามวันแล้วพับได้ |

## สถานะในระบบใหม่

ตรวจจากโค้ดเมื่อ 2026-11-03 และแก้ 5 ข้อใน [สิ่งที่แก้ไปแล้ว](#สิ่งที่แก้ไปแล้ว) ในวันเดียวกัน · ✅ แก้แล้ว · 🟡 แก้บางส่วน · ❌ ยังไม่แก้

### ภาพรวมรายข้อ

### สิ่งที่แก้ไปแล้ว

1. **บั๊ก** หน้าผู้ไม่มีสิทธิ์สอบโหลดค่าค้นล่าสุดกลับแล้ว และบันทึกทุกครั้งที่ค้น ไม่ใช่เฉพาะตอนเลือกห้องหรือวิชา
2. **ปีปัจจุบัน** ข้อมูลจำลองของหน้ารายงานที่เคยใช้ 2568 เลื่อนเป็น 2569 (ปีก่อนหน้าเลื่อนตามทีละ 1 ปี) ให้ตรงกับตารางสอนและ grading · ค่ากลางอยู่ที่ `CURRENT_TERM` ใน [shared/academic-layout.js](../shared/academic-layout.js)
3. **การจำค่าที่ค้น** ทุกหน้ารายงานใช้ `AcademicLayout.lastSearch()` บันทึกลง `localStorage` (คีย์ดูที่ [data.md](data.md#คีย์ใน-localstorage))
4. **ผลการเรียนรายวิชา** เพิ่ม Cascading และตัวกรองห้อง / แผนการเรียน
5. **ตารางรวม** ช่องในตารางแสดงรหัสวิชา ครู และห้อง

### ที่ยังเหลือ

- ปุ่มส่งออกทุกหน้าเป็น mock (P5) และ Preview ทะเบียนสะสมเป็นข้อความตัวอย่าง (P6)
- คะแนนเฉลี่ยรายปีเรียงลำดับไม่ได้ (P3)
- "อัปเดตล่าสุดวันนี้" ในข้อมูลรายวิชาเป็นข้อความคงที่ (P8)
- ภาคเรียนเริ่มต้นยังไม่ได้อ่านจาก `AcademicLayout.currentTerm` แต่ละหน้าใช้ภาคล่าสุดที่มีข้อมูล
- ฝั่งวิชาการยังไม่มีหน้าตรวจสอบการเช็กชื่อ และ 4 หน้าระบบเดิมที่ยังไม่มีหน้าตรง
