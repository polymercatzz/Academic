# Actor และบทบาท

ไฟล์นี้เป็นที่นิยามบทบาทของทั้งระบบ อภิธานศัพท์ของแต่ละโมดูลอ้างมาที่นี่

## นิยาม

**admin**:
งานวิชาการ ผู้มีสิทธิ์จัดการหลักสูตร สร้าง จัด และเผยแพร่ตารางสอน และเป็นผู้ตรวจ อนุมัติ หรือตีกลับผลการเรียนที่ครูส่ง ในโมดูลบันทึกคะแนนเรียกว่า **ครูฝ่ายวิชาการ** ซึ่งดูข้อมูลได้ทุกห้องแต่แก้คะแนนไม่ได้ ([grading ADR 0001](../grading/docs/adr/0001-academic-view-only-and-return.md))
_Avoid_: ผู้ดูแลระบบ, ครูวิชาการ, ฝ่ายทะเบียน

**ครู**:
ครูผู้สอน ดูตารางสอนฉบับเผยแพร่ได้อย่างเดียว (ตารางสอนของตนเอง ตารางเรียนทุกห้อง และตารางการใช้ทุกห้อง) กำหนดเวลาไม่ว่างของตนเอง ยื่นคำร้องขอเปลี่ยนการจัด และบันทึกคะแนน เช็คชื่อ และส่งผลการเรียนของห้องที่ตนสอน

บทบาทย่อยของครู (ไม่ใช่บทบาทแยกในระบบ ดูรายละเอียดใน [grading/GLOSSARY.md](../grading/GLOSSARY.md#บทบาท-role))

- **ครูประจำชั้น**: ดูการเข้าเรียนของห้องตนเองได้ทุกวิชาทุกคาบ แต่แก้สถานะที่ครูผู้สอนเช็คไว้ไม่ได้
- **ครูที่ปรึกษาชุมนุม**: บันทึกผล ผ / มผ ของชุมนุม
- **ครูร่วมสอน**: ครูมากกว่าหนึ่งคนที่สอนรายวิชาเดียวกันให้ห้องเดียวกัน ([timetable/GLOSSARY.md](../timetable/GLOSSARY.md))

คนเดียวมีได้หลายบทบาท เช่น ครูที่ได้รับบทบาทฝ่ายวิชาการด้วย สลับมุมมองได้ และตรวจห้องที่ตนสอนได้แต่ระบบติดป้าย "ตรวจงานตนเอง" ([grading ADR 0003](../grading/docs/adr/0003-dual-role-switcher.md), [0007](../grading/docs/adr/0007-self-review-allowed-with-label.md))

## ผู้ที่ไม่ได้ใช้ระบบโดยตรง

| ใคร | เกี่ยวข้องอย่างไร |
|---|---|
| นักเรียน | เป็นข้อมูลในระบบ (คะแนน เวลาเรียน ผลการเรียน) ไม่มีหน้าจอของตัวเอง |
| งานบุคคล | เจ้าของข้อมูลครูและวิชาที่ครูสอนได้ จำลองไว้ใน [timetable-data.js](../timetable/timetable-data.js) |
| อาคารสถานที่ | เจ้าของข้อมูลห้องเรียนและห้องเฉพาะทาง จำลองไว้ใน `timetable-data.js` |
| ผู้อำนวยการ | ขั้นอนุมัติของผู้อำนวยการอยู่นอกขอบเขตของรอบนี้ ([grading spec](../grading/docs/spec-academic-role.md)) |

## สิทธิ์ตามหน้า

| งาน | admin | ครู |
|---|---|---|
| จัดการหลักสูตร แผนการเรียน รายวิชา มอบหมายสอน | ✔ | — |
| สร้าง จัด และเผยแพร่ตารางสอน | ✔ | — |
| อนุมัติคำร้องขอเปลี่ยนการจัด และเวลาไม่ว่างของครู | ✔ | — |
| ดูตารางสอนฉบับเผยแพร่ | ✔ | ✔ |
| กรอกเวลาไม่ว่าง และยื่นคำร้องขอเปลี่ยนการจัด | — | ✔ |
| ตั้งโครงสร้างคะแนน กรอกคะแนน ส่งผล ขอปลดล็อก | — | ✔ |
| เช็คชื่อรายคาบ ดูห้องประจำชั้น | — | ✔ |
| ดูภาพรวมผลการเรียน ตรวจ อนุมัติ ตีกลับ พิจารณาคำขอปลดล็อก | ✔ (แก้คะแนนไม่ได้) | — |
| รายงานวิชาการ | ✔ | เฉพาะรายงานการเข้าเรียนของตนเอง |

การบังคับสิทธิ์มีแค่ระดับหน้าจอ หน้าตารางสอนแสดงข้อความ "หน้านี้สำหรับ admin/ครู" เมื่อบทบาทไม่ตรง ส่วนหน้าอื่นแค่ไม่อยู่ในเมนูของบทบาทนั้น ถ้าเปิด URL ตรง ๆ ก็ยังเข้าได้
