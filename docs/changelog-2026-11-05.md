## 3. รายงานวิชาการ (`reports/`, `assets/academic-report/`)

### 3.1 รายงานการเข้าเรียน (`academic-report.html`)
- ตัดตัวกรอง "ระดับชั้น" ออก · ตัวเลือกห้องจัดกลุ่มตามระดับชั้น (optgroup)
- การ์ด "มาเรียน" + "การลา" → การ์ด **% ขาดเรียน** (ขาด X จาก Y คาบ)
- กราฟแนวโน้มแยก 2 แผง: เข้าเรียน / ขาดเรียนและมาสาย · ค้นหารายเดือนแสดงทั้งภาคและไฮไลต์เดือนที่เลือก
- "นักเรียนที่เสี่ยงไม่มีสิทธิ์สอบ" → **กลุ่มเสี่ยง มส**

### 3.2 รายงานผู้ไม่มีสิทธิ์สอบ
- ครูเข้าได้ (เมนูใหม่ในแถบข้าง) และเห็นเฉพาะห้อง/วิชาที่ตนสอน · ฝ่ายวิชาการเห็นทั้งโรงเรียน
- จัดกลุ่มเฉพาะวิชาที่มี มส ตามลำดับกลุ่มสาระ · หัวตาราง "ชั้น/ห้อง" → "ห้อง"

### 3.3 รายงานการเข้าเรียนของครู (`teacher-attendance.html`)
- การ์ดสรุปเหลือ 4 ใบ: เพิ่ม **% ขาดเรียน** ตัด "อัตราการเข้าเรียน" และ "การลา"
- กลุ่มเสี่ยง มส ใช้กฎเดียวกับรายงานฝ่ายวิชาการ: เสี่ยงเมื่อขาดถึงครึ่งของที่ขาดได้ เกินแล้ว = มส (สีส้ม/แดงแยกกัน) · แสดงครบทุกคน ไม่ตัดที่ 6 คน

### 3.4 ปรับคำให้ตรงความหมาย (เลิกใช้คำกว้างๆ "ต้องติดตาม")
| หน้า | เดิม → ใหม่ |
|---|---|
| ภาพรวม (`overview.html`) | นักเรียนต้องติดตาม → **นักเรียนติด 0 / ร / มส** |
| คะแนนเฉลี่ยรายปี | ต้องติดตาม → **คะแนนต่ำกว่าเกณฑ์** · จัดอันดับด้วยเกรดเฉลี่ย · ปุ่มกลับภาพรวมใช้ได้แม้ค้นหาห้องโดยตรง · "ความครบถ้วน %" → **ครูกรอกคะแนนแล้ว x/y** |
| รายงานผลการเรียนสะสม | ควรติดตาม → **ผลสะสมต่ำกว่า 2.00** · ความครบถ้วนของข้อมูล → **มีผลการเรียนครบทุกภาค x/y คน** · ชื่อกราฟหน่วยกิตชัดขึ้น |
| คะแนนรายวิชา | คะแนนที่กรอกแล้ว % → **ครูกรอกคะแนนแล้ว x/y** (+%) |
| สอบซ่อมรายห้อง | ต้องติดตาม → **มีงานค้าง / เร่งด่วนปานกลาง** · หัวตารางภาษาอังกฤษ → ไทย · รวมสถานะเป็นชิปเดียวต่อคน แสดงเฉพาะสถานะที่มี |
| จัดอันดับคะแนน (+ รายละเอียด) | ต้องติดตาม → **ต่ำกว่าเกณฑ์** · ตัวเลือกเรียงขึ้นต้น "เรียงตาม:" · ค่าเริ่มต้นเรียงรหัสวิชาแล้วห้อง |

### 3.5 อื่น ๆ
- ตารางคะแนนรายนักเรียน: คอลัมน์เกรด/อันดับที่ล็อกไว้แคบลง
