# เอกสารภาพรวม — Academic Report

เอกสารสำหรับนักพัฒนาที่เพิ่งเข้ามาในโปรเจกต์ อ่านตามลำดับนี้

| ไฟล์ | อ่านเมื่อ |
|---|---|
| [overview.md](overview.md) | อยากรู้ว่าระบบนี้คืออะไร ประกอบด้วยอะไร และหน้าต่าง ๆ ต่อกันอย่างไร |
| [actors.md](actors.md) | อยากรู้ว่าใครใช้ระบบ แต่ละบทบาททำอะไรได้ และนิยามบทบาทของทั้งระบบ |
| [personas.md](personas.md) | อยากรู้ว่าตัวละครใน demo คือใคร มีเป้าหมายอะไร และสาธิตตามลำดับไหน |
| [pain-points.md](pain-points.md) | อยากรู้ว่าระบบเดิมมีปัญหาอะไร และหน้าใหม่หน้าไหนรับช่วงงานนั้น |
| [modules.md](modules.md) | ต้องแก้หน้าใดหน้าหนึ่ง แล้วอยากรู้ว่าหน้านั้นทำอะไร ใช้ไฟล์ไหน |
| [data.md](data.md) | ต้องแก้ข้อมูลจำลอง หรือสงสัยว่าข้อมูลเก็บที่ไหน · มีหัวข้อจุดที่ยังไม่เชื่อมกัน |
| [database/](database/README.md) | ออกแบบฐานข้อมูลจริง (PostgreSQL) ทีละขอบเขต |
| [adding-a-page.md](adding-a-page.md) | จะเพิ่มหน้าใหม่ หรือแก้ sidebar กลาง |
| [GLOSSARY-MAP.md](GLOSSARY-MAP.md) | หาอภิธานศัพท์และ ADR ของแต่ละโมดูล |

เอกสารเฉพาะโมดูลอยู่ในโฟลเดอร์ของโมดูลนั้น

- บันทึกคะแนนและเช็คชื่อ: [grading/README.md](../grading/README.md) · [grading/GLOSSARY.md](../grading/GLOSSARY.md) · [grading/docs/](../grading/docs/) (ADR, spec, ER)
