# ฉบับเผยแพร่ของตารางสอนแก้ไขไม่ได้ การเปลี่ยนแปลงทุกครั้งสร้างฉบับใหม่

ตารางสอนหนึ่งภาคเรียนมีได้หลายฉบับ แต่ฉบับเผยแพร่แก้ไขไม่ได้เลย admin ต้องคัดลอกออกมาเป็นฉบับร่างแล้วเผยแพร่ใหม่ ส่วนการอนุมัติคำร้องขอเปลี่ยนการจัดของครู ระบบสร้างฉบับเผยแพร่ใหม่ (= ฉบับเดิม + การเปลี่ยนแปลง) ให้ทันที แล้วเปลี่ยนฉบับเดิมเป็นฉบับเก่า เราเลือกแบบนี้แทนการแก้ฉบับเผยแพร่ตรง ๆ เพราะครูใช้ตารางที่เผยแพร่แล้วในการสอนจริง ทุกการเปลี่ยนแปลงจึงต้องย้อนดูได้ว่าตารางเคยเป็นอย่างไร ใครเปลี่ยน และเพราะอะไร

## Consequences

- ฉบับร่างที่คัดลอกมาจากฉบับเผยแพร่ ล้าหลังได้ทันทีที่มีการอนุมัติคำร้อง ระบบจึงต้องแสดงในฉบับร่างว่ามีการเปลี่ยนแปลงอะไรหลังคัดลอก และมีปุ่มให้นำมารวม
- ประวัติของภาคเรียนหนึ่งคือลำดับของฉบับ ไม่ใช่บันทึกการแก้ไขบนฉบับเดียว
