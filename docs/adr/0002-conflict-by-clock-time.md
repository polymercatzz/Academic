# ตรวจ Conflict ด้วยเวลาจริง ไม่ใช้เลขคาบ

แต่ละช่วงชั้นมีโครงสร้างเวลาของตัวเองได้ (เช่น ม.ต้นคาบละ 50 นาที พัก 11:50 ส่วน ม.ปลายคาบละ 55 นาที พัก 12:10) ทำให้ "คาบที่ 5" ของสองช่วงชั้นเป็นคนละเวลากัน เราจึงตัดสินว่าครูหรือห้องซ้อนกันจากช่วงเวลาจริงที่ทับกัน แทนการเทียบวันกับเลขคาบ และตารางสอนครูกับตารางการใช้ห้องแสดงเป็นแกนเวลาแทนช่องตามเลขคาบ ส่วนตารางเรียนรายห้องยังแสดงตามเลขคาบของช่วงชั้นนั้นตามปกติ

## Considered Options

- บังคับให้ทุกช่วงชั้นใช้เวลาคาบเดียวกัน แล้วตรวจด้วยเลขคาบ: ไม่เลือก เพราะโรงเรียนจริงที่ ม.ต้นกับ ม.ปลายพักไม่พร้อมกันจะใช้ระบบนี้ไม่ได้
