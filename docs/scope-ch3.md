# ร่างขอบเขตของระบบ (บทที่ 3) — แยกตามระบบย่อย

> ร่างจากหน้าจอในเดโม ([modules.md](modules.md)), สิทธิ์ตามบทบาท ([actors.md](actors.md)) และ use case 26 ตัวในรูป 3.2 ([usecase/](usecase/))
> เลข UC ในวงเล็บใช้ตรวจความสอดคล้องกับภาคผนวก ก — ลบออกได้ถ้าไม่ต้องการให้ปรากฏในเล่ม

ระบบบริหารจัดการงานวิชาการภายในโรงเรียนแบ่งออกเป็น 6 ระบบย่อย มีผู้ใช้งาน 2 บทบาทหลัก ได้แก่ ครูฝ่ายวิชาการ และครูผู้สอน (ครูประจำชั้นและครูที่ปรึกษาชุมนุมเป็นบทบาทย่อยของครูผู้สอน) โดยแต่ละระบบย่อยมีขอบเขตดังนี้

---

## 1. ระบบจัดการรายวิชาและหลักสูตร

**Actor:** ครูฝ่ายวิชาการ (จัดการ), ครูผู้สอน (ดูอย่างเดียว)

**ทำอะไรได้บ้าง**

1. ครูฝ่ายวิชาการเพิ่ม แก้ไข ทำสำเนา และลบรายวิชา โดยระบบสร้างรหัสวิชาอัตโนมัติตามหลักการกำหนดรหัสวิชา และนำเข้ารายวิชาจากไฟล์ Excel ได้ โดยระบบตรวจข้อมูลก่อนยืนยัน (UC-2)
2. ครูฝ่ายวิชาการกำหนดกลุ่มสาระการเรียนรู้ หน่วยกิต จำนวนชั่วโมง องค์ประกอบคะแนนตั้งต้น เกณฑ์ผ่าน และตัวชี้วัดของแต่ละรายวิชา (UC-2)
3. ครูฝ่ายวิชาการจัดการหลักสูตรและแผนการเรียนของแต่ละระดับชั้น (เพิ่ม แก้ไข ทำสำเนา ลบ นำเข้า) และเพิ่มรายวิชาเข้าแผนการเรียน (UC-3)
4. ครูฝ่ายวิชาการมอบหมายครูผู้สอนให้แต่ละรายวิชาในแต่ละห้องเรียน รองรับครูร่วมสอน และให้ระบบกำหนดครูอัตโนมัติได้ (UC-3)
5. ครูฝ่ายวิชาการและครูผู้สอนดูโครงสร้างหลักสูตรแกนกลาง พ.ศ. 2551 โครงสร้างเวลาเรียน และเกณฑ์การวัดผลและการจบหลักสูตร (UC-1)

---

## 2. ระบบจัดการตารางสอน

**Actor:** ครูฝ่ายวิชาการ, ครูผู้สอน

**ทำอะไรได้บ้าง**

ครูฝ่ายวิชาการ

1. สร้างตารางสอนฉบับร่างใหม่ หรือคัดลอกจากฉบับเดิม และจัดการฉบับ (ฉบับร่าง / ฉบับเผยแพร่ / ฉบับเก่า) (UC-4)
2. กำหนดโครงสร้างเวลาแยกตามช่วงชั้น และกิจกรรมที่ล็อกเวลาไว้ เช่น โฮมรูม ชุมนุม (UC-4)
3. จัดตารางสอนได้ 3 วิธี ได้แก่ จัดด้วยตนเองแบบลากวาง จัดอัตโนมัติ และจัดอัตโนมัติแบบกำหนดเงื่อนไข (UC-5, 6, 7)
4. ระบบตรวจสอบการชนกันของครู ห้องเรียน และห้องเฉพาะทางโดยเทียบจากเวลาจริง รวมถึงเวลาไม่ว่างของครูและห้องที่ไม่พร้อมใช้ (UC-8)
5. บันทึกและเผยแพร่ตารางสอน เมื่อเผยแพร่แล้วตารางฉบับนั้นแก้ไขไม่ได้ ต้องสร้างฉบับใหม่ (UC-9)
6. พิจารณาคำร้องขอเปลี่ยนการจัดตารางสอน (อนุมัติ / อนุมัติพร้อมแก้ไข / ไม่อนุมัติ) โดยดูตารางก่อนและหลังเปลี่ยน (UC-21)
7. พิจารณาเวลาไม่ว่างของครูที่ครูกรอกเข้ามา (UC-22)

ครูผู้สอน

1. ดูตารางสอนของตนเอง ตารางเรียนรายห้อง และตารางการใช้ห้อง จากฉบับที่เผยแพร่แล้ว (UC-10)
2. ยื่นหรือยกเลิกคำร้องขอเปลี่ยนการจัดตารางสอน (UC-21)
3. กรอก แก้ไข ลบ หรือคัดลอกเวลาไม่ว่างประจำสัปดาห์จากภาคเรียนก่อน ได้จนถึงวันปิดรับ (UC-22)

## 3. ระบบบันทึกคะแนน

**Actor:** ครูผู้สอน, ครูที่ปรึกษาชุมนุม, ครูฝ่ายวิชาการ

**ทำอะไรได้บ้าง**

ครูผู้สอน

1. กำหนดโครงสร้างคะแนนของห้องเรียนที่ตนสอน (คัดลอกจากโครงสร้างตั้งต้นของรายวิชา) ซึ่งต้องรวมได้ร้อยละ 100 และผูกกับตัวชี้วัด (UC-11)
2. บันทึกคะแนนนักเรียน รองรับการกรอกด้วยคีย์บอร์ดและการวางข้อมูลจาก Excel และดูประวัติการแก้ไขคะแนน (UC-12)
3. ประเมินคุณลักษณะอันพึงประสงค์ และการอ่าน คิดวิเคราะห์ และเขียน (UC-25)
4. ส่งผลการเรียนให้ฝ่ายวิชาการตรวจ โดยระบบตรวจความครบถ้วนก่อนส่ง (UC-17)
5. ขอปลดล็อกผลการเรียนที่ส่งหรืออนุมัติแล้วเพื่อกลับมาแก้ไข (UC-19)
6. บันทึกผลการสอบซ่อมของนักเรียนที่ได้ระดับ 0 ได้ไม่เกิน 2 ครั้ง ถ้าผ่านจะได้ระดับ 1 (UC-20)
7. ดูรายชื่อนักเรียนที่ต้องติดตาม (0 / ร / มส) ในห้องที่ตนสอน

ครูที่ปรึกษาชุมนุม

1. เพิ่มหรือนำสมาชิกออกจากชุมนุม กรอกเวลาเข้าร่วม บันทึกผลกิจกรรม ผ่าน / ไม่ผ่าน และส่งผลให้ฝ่ายวิชาการ (UC-26)

ระบบ

1. คำนวณผลการเรียนอัตโนมัติจากคะแนนและเกณฑ์การตัดสิน (UC-13)
2. ตรวจสอบสถานะผ่าน / ไม่ผ่านเกณฑ์ รวมถึง 0 / ร / มส (UC-14)

ครูฝ่ายวิชาการ

1. ดูภาพรวมสถานะการส่งผลการเรียนทั้งโรงเรียนในรูปแบบตาราง ห้อง × รายวิชา และรายครู (UC-15)
2. ตรวจผลการเรียนแบบอ่านอย่างเดียว ปักหมุดข้อสังเกต แล้วอนุมัติ หรือตีกลับพร้อมเหตุผล และอนุมัติหลายห้องพร้อมกันได้ ฝ่ายวิชาการแก้ไขคะแนนเองไม่ได้ (UC-18)
3. พิจารณาคำขอปลดล็อกผลการเรียน (UC-19)
4. เปิดชุมนุม กำหนดครูที่ปรึกษาและจำนวนรับ แล้วตรวจ อนุมัติ หรือตีกลับผลชุมนุม (UC-26)

## 4. ระบบเช็คชื่อ

**Actor:** ครูผู้สอน, ครูประจำชั้น, ครูฝ่ายวิชาการ

**ทำอะไรได้บ้าง**

1. ครูผู้สอนเช็คชื่อนักเรียนรายคาบจากคาบที่สอนในวันนั้น (มา / สาย / ลา / ขาด) และดูคาบที่ยังไม่ได้เช็ค (UC-23)
2. ระบบคำนวณร้อยละเวลาเรียนรายนักเรียน และแสดงกลุ่มเสี่ยงและผู้ไม่มีสิทธิ์สอบ (มส) ของห้องที่ครูสอน (UC-24)
3. ครูประจำชั้นดูการเข้าเรียนของห้องตนเองได้ทุกวิชาทุกคาบ และดูสรุปทั้งภาคเรียน แต่แก้สถานะที่ครูผู้สอนเช็คไว้ไม่ได้ (UC-24)
4. คาบในวันหยุดของโรงเรียนไม่ต้องเช็คชื่อและไม่นับเป็นเวลาเรียน (วันหยุดมาจากข้อมูลตั้งต้น ไม่มีหน้าจอกำหนดวันหยุด) (UC-23)

---

## 5. ระบบรายงานวิชาการ

**Actor:** ครูฝ่ายวิชาการ, ครูผู้สอน (เฉพาะรายงานการเข้าเรียนของตนเอง)

**ทำอะไรได้บ้าง**

1. ครูฝ่ายวิชาการดูภาพรวมความคืบหน้างานวิชาการของปีการศึกษา งานที่ต้องดำเนินการ และนักเรียนที่ต้องติดตาม (UC-16)
2. ครูฝ่ายวิชาการดูรายงานต่อไปนี้ โดยกรองตามปีการศึกษา ภาคเรียน ระดับชั้น ห้อง และรายวิชาได้ (UC-16)
   - รายงานการเข้าเรียน และรายงานผู้ไม่มีสิทธิ์สอบ
   - รายงานคะแนนรายวิชา และรายงานจัดอันดับคะแนนรายวิชา
   - รายงานคะแนนเฉลี่ยรายปี
   - รายงานสรุปผลการเรียนรู้
   - รายงานนักเรียนที่ต้องปรับปรุง (0 / ร / มส)
   - รายงานผลการสอบซ่อม แยกรายนักเรียน รายวิชา และรายห้อง
   - รายงานระเบียนสะสม เกรดเฉลี่ยสะสม (GPAX) และหน่วยกิตสะสม
3. ครูผู้สอนดูรายงานการเข้าเรียนของห้องที่ตนสอน (UC-16)

## นอกขอบเขต (อ้างข้อ 1.3.4)

- การจัดการบัญชีผู้ใช้และการยืนยันตัวตน — ใช้ User Management Service ของอีกทีม
- ข้อมูลครูและห้องเรียนต้นทาง — เป็นของงานบุคคลและงานอาคารสถานที่
- นักเรียนและผู้ปกครองไม่มีหน้าจอของตนเอง
- ขั้นอนุมัติผลการเรียนโดยผู้อำนวยการ
