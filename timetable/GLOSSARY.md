# ระบบงานวิชาการ — ตารางสอน

ภาษากลางของการสร้าง จัด และเผยแพร่ตารางสอนของโรงเรียนในแต่ละภาคเรียน

## ตารางสอนและฉบับ

**ตารางสอน**:
ชุดคาบเรียนทั้งหมดของทุกครูและทุกห้องในหนึ่งภาคเรียน หนึ่งภาคเรียนมีตารางสอนได้หลายฉบับ
_Avoid_: ตารางเรียน (เมื่อหมายถึงทั้งชุด), schedule

**ฉบับร่าง**:
ฉบับของตารางสอนที่ admin แก้ไขได้ สร้างใหม่ทั้งหมดหรือคัดลอกจากฉบับที่มีอยู่
_Avoid_: draft, ตารางชั่วคราว

**ฉบับเผยแพร่**:
ฉบับของตารางสอนที่ครูเห็นและใช้จริง แก้ไขไม่ได้ การเปลี่ยนแปลงต้องทำผ่านฉบับร่างที่คัดลอกมา
_Avoid_: ตารางจริง, published

**ฉบับเก่า**:
ฉบับเผยแพร่ที่ถูกแทนที่ด้วยฉบับใหม่ ดูย้อนหลังได้แต่ไม่ใช้งาน หนึ่งภาคเรียนมีฉบับเผยแพร่ได้ทีละหนึ่งฉบับ
_Avoid_: archive, ฉบับยกเลิก

**การคัดลอกตารางสอน**:
การสร้างฉบับร่างโดยนำการตั้งค่าและคาบจากฉบับที่มีอยู่ จับคู่ด้วยชื่อห้องและรหัสวิชา คาบที่ไม่ตรงกับการมอบหมายสอนของภาคเรียนปลายทางจะถูกตัดทิ้งและแจ้งให้ทราบ

## ข้อมูลก่อนจัด

**โครงสร้างเวลา**:
วันที่เรียน เวลาเริ่มเรียน ความยาวคาบ จำนวนคาบต่อวัน ช่วงพัก และวันที่ไม่มีเรียน กำหนดตั้งแต่ตอนสร้างตารางสอน หนึ่งตารางสอนมีได้หลายชุด แต่ละชุดใช้กับช่วงชั้นของตน

**ช่วงชั้น**:
กลุ่มระดับชั้นที่ใช้โครงสร้างเวลาชุดเดียวกัน admin จัดกลุ่มเอง ค่าเริ่มต้นคือ ม.ต้น และ ม.ปลาย
_Avoid_: ระดับ (เมื่อหมายถึงกลุ่มหลายระดับชั้น)

**แผนการเรียน**:
ชุดรายวิชาแยกตามภาคเรียนของระดับชั้นหนึ่ง และกลุ่มห้องที่เรียนตามแผนนั้น รายวิชาของห้องในภาคเรียนหนึ่งคือรายวิชาของแผนที่ห้องสังกัด
_Avoid_: สายการเรียน, โปรแกรม

**วิชาที่ครูสอนได้**:
รายวิชาที่ครูแต่ละคนมีสิทธิ์สอน เป็นข้อมูลจากทีมอื่น ใช้เป็นตัวเลือกตอนมอบหมายสอน
_Avoid_: ความถนัด, การมอบหมายสอน

**การมอบหมายสอน**:
การกำหนดว่าครูคนใดสอนรายวิชาใดในแผนการเรียน ให้ห้องใดบ้าง ทำที่หน้าจัดการหลักสูตร และเป็นที่มาของคาบที่ต้องจัด
_Avoid_: assignment, ภาระสอน (ภาระสอนคือผลรวมคาบของครู)

**คาบต่อสัปดาห์**:
จำนวนคาบที่รายวิชาต้องเรียนในหนึ่งสัปดาห์ เท่ากับจำนวนชั่วโมงต่อสัปดาห์ของรายวิชา โดยไม่ขึ้นกับความยาวคาบ

**กิจกรรมล็อกเวลา**:
กิจกรรมที่ทั้งโรงเรียน ช่วงชั้น หรือระดับชั้นต้องเข้าร่วมพร้อมกันในช่วงเวลาที่กำหนดตายตัว เช่น เข้าแถว โฮมรูม ชุมนุม ลูกเสือ ประชุมครู ห้ามจัดคาบอื่นทับ และนับครูที่เกี่ยวข้องว่าไม่ว่าง
_Avoid_: กิจกรรมส่วนกลาง (ใช้เมื่อพูดถึงประเภทกิจกรรมเท่านั้น)

**เวลาไม่ว่างของครู**:
ช่วงเวลาประจำสัปดาห์ในภาคเรียนหนึ่งที่ครูสอนไม่ได้เพราะมีภารกิจในโรงเรียน ไม่ใช่ธุระส่วนตัว มีผลเป็นข้อบังคับเมื่อ admin อนุมัติแล้วเท่านั้น ครูกรอกได้จนถึงวันปิดรับเวลาไม่ว่าง

**วันปิดรับเวลาไม่ว่าง**:
วันสุดท้ายที่ครูกรอกหรือแก้เวลาไม่ว่างของภาคเรียนนั้นได้ admin กำหนดตอนสร้างตารางสอน

**การตรวจความพร้อม**:
การตรวจข้อมูลก่อนจัดตาราง ผลแบ่งเป็น "ไม่ผ่าน" ซึ่งทำให้จัดอัตโนมัติไม่ได้ และ "คำเตือน" ซึ่งทำต่อได้

## การจัดตาราง

**จัดเอง**:
วิธีจัดที่ admin ลากวางคาบจากรายการรอจัดทั้งหมดเอง ระบบเตือนเมื่อขัดเงื่อนไขแต่ยอมให้วาง ยกเว้นห้องมีคาบอยู่แล้วหรือทับกิจกรรมล็อกเวลา

**จัดอัตโนมัติตามเงื่อนไข**:
วิธีจัดที่ระบบวางคาบให้ทั้งหมดโดยเคารพเงื่อนไขมาตรฐานและเงื่อนไขที่ admin กำหนดเพิ่ม

**จัดอัตโนมัติมาตรฐาน**:
วิธีจัดที่ระบบวางคาบให้โดยเคารพเฉพาะเงื่อนไขมาตรฐาน ไม่สนเงื่อนไขที่ admin กำหนดเพิ่ม

**เงื่อนไขมาตรฐาน**:
กฎที่ระบบบังคับเสมอ ได้แก่ ครูไม่สอนซ้อน ห้องไม่ใช้ซ้อน ห้องนักเรียนมีวิชาเดียวต่อคาบ ไม่เกินจำนวนคาบต่อวัน ไม่ทับกิจกรรมล็อกเวลา คาบต่อสัปดาห์ตรงหลักสูตร และวิชาเดียวกันไม่เกิน 2 คาบต่อวัน

**ข้อบังคับ**:
เงื่อนไขที่การจัดอัตโนมัติจะไม่ละเมิดเด็ดขาด ถ้าจัดไม่ได้ คาบนั้นจะค้างอยู่ในรายการรอจัดพร้อมเหตุผล

**ข้อพึงประสงค์**:
เงื่อนไขที่การจัดอัตโนมัติพยายามทำตาม แต่ละเลยได้ ได้แก่ ช่วงเช้า/บ่ายที่ควรเรียน และระดับความสำคัญของวิชา

**ครูร่วมสอน**:
ครูมากกว่าหนึ่งคนที่ได้รับมอบหมายสอนรายวิชาเดียวกันให้ห้องเดียวกัน คาบนั้นนับเป็นคาบสอนของครูทุกคน และต้องจัดในช่วงที่ทุกคนว่างพร้อมกัน
_Avoid_: ครูสอนแทน

**รายการรอจัด**:
คาบที่ได้จากการมอบหมายสอนแต่ยังไม่ได้วางลงตารางสอน

**Conflict**:
คาบที่ละเมิดเงื่อนไขมาตรฐาน หรือตรงกับเวลาไม่ว่างของครูที่อนุมัติแล้ว ตัดสินการซ้อนจากเวลาจริงที่ทับกัน ไม่ใช่เลขคาบ ฉบับร่างที่ยังมี Conflict เผยแพร่ไม่ได้
_Avoid_: ตารางชน, การชน (ใช้ได้ในบทสนทนา แต่ในระบบใช้ Conflict)

**คำเตือน**:
คาบที่ขัดเงื่อนไขที่ admin กำหนดเพิ่ม เช่น ห้องไม่ตรงประเภท หรือคาบติดกันเกินกำหนด ไม่ขวางการเผยแพร่

## คำร้อง

**คำร้องขอเปลี่ยนการจัด**:
คำขอของครูให้ย้ายคาบ สลับคาบของตนเอง หรือเปลี่ยนห้องเรียน ในฉบับเผยแพร่แบบถาวร ต้องมีหมายเหตุและรอ admin อนุมัติ
_Avoid_: คำร้องสอนแทน (การขาดสอนรายวันเป็นคนละเรื่อง), ticket
