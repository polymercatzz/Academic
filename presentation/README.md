4. **น้ำหนักเรื่อง AI-native SDLC** — แค่ 1 สไลด์ หรือขยายเป็นจุดเด่น
5. **ธีม/เทมเพลต** — ใช้เทมเพลตคณะ IT KMITL หรือออกแบบเอง
