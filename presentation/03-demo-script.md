# สคริปต์เดโมต้นแบบ (ประมาณ 4:10 · 6 คลิป · สไลด์ Demo)

เป้าหมาย: ให้กรรมการเห็นว่า **กฎที่เพิ่งเห็นใน Activity และ State ทำงานจริงในต้นแบบ** — ไม่ใช่แค่หน้าจอสวย
เล่าเป็นเรื่องเดียว: "หนึ่งภาคเรียนของ อ.สุนิสา กับครูสมศรี" ครบทั้ง 5 ระบบย่อย เริ่มจากหลักสูตรจนถึงรายงาน

## เครื่องมือกรอกข้อมูลตอนอัด

ทุกหน้าโหลด `shared/demo-autofill.js` ไว้แล้ว ไม่ต้องตั้งค่าเพิ่ม

- **F9** กรอกให้ตามหน้าจอที่เปิดอยู่ ระบบไม่กดบันทึก ส่ง หรือยืนยันแทน ผู้นำเสนอกดเองในวิดีโอ
- **F8** เปิดแผงเลือกคำสั่งเองและตั้งความเร็ว ช้า ปกติ เร็ว แผงจะซ่อนเองระหว่างกรอก

| หน้าจอ | กด F9 แล้วได้อะไร |
|---|---|
| หน้าต่างที่มีช่องข้อความว่าง | พิมพ์ชื่อแผน เหตุผลตีกลับ ข้อความหมุด เหตุผลขอปลดล็อก หรือคำยืนยัน "เผยแพร่" |
| เพิ่มรายวิชาเข้าแผน | ติ๊กรายวิชา 3 วิชาแรกที่ยังไม่อยู่ในแผน |
| สร้างตารางสอนใหม่ ขั้นกิจกรรมล็อกเวลา | เพิ่มกิจกรรมเพื่อสังคม ระดับชั้น ม.3 วันศุกร์ คาบ 6 |
| โครงสร้างคะแนน | เริ่มจากว่างแล้วพิมพ์ 6 องค์ประกอบ รวม 100% |
| ตารางคะแนน แท็บคะแนน | เปิดหน้าต่างนำเข้า ทำไฟล์ CSV ที่เติมช่องว่างครบ แล้วนำเข้าให้ |
| ตารางคุณลักษณะ หรือ อ่านคิดเขียน | เติมระดับ 1–3 ในช่องที่ยังว่าง |
| เช็คชื่อรายคาบ | ขาด 2 คน สาย 1 คน ลา 1 คน คนที่เวลาเรียนต่ำสุดจะเป็นขาด |

ถ้าอยากให้เห็นการลากไฟล์จริง กด F8 แล้วเลือก "บันทึกไฟล์ CSV ตัวอย่างลงเครื่อง" จากนั้นลากไฟล์นั้นไปวางเอง
