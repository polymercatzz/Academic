# วิดีโอเดโมต้นแบบ

วิดีโอเดโมอัดจากต้นแบบตามเส้นทางใน [03-demo-script.md](03-demo-script.md) ตัดต่อตามแผนใน [04-video-edit-plan.md](04-video-edit-plan.md)
ใช้เปิดในสไลด์ Demo แล้วพูดสดประกอบ วิดีโอไม่มีเสียงและไม่มีตัวหนังสือ มีแค่กรอบกับการซูม
ยาวประมาณ 4:10 นาที ถ้าหยุดตอบคำถามระหว่างคลิปยังไม่เกิน 4:30 นาที

> **สถานะ** กำลังอัดใหม่ทั้งหมด เวลาในไฟล์นี้เป็นเวลาเป้าหมาย ตัดต่อเสร็จแล้วค่อยแก้เป็นเวลาจริง

## ไฟล์

โฟลเดอร์ `clip demo/` ไม่อยู่ใน git เพราะเป็นไฟล์วิดีโอขนาดใหญ่ เก็บไว้ในเครื่องและ USB สำรอง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `clip demo/edited/0-รวมทุกระบบ.mp4` | **ไฟล์ที่ใส่ในสไลด์** |
| `clip demo/edited/1-หลักสูตร.mp4` ถึง `6-รายงาน.mp4` | คลิปแยกรายระบบ ถ้าจะเปลี่ยนเป็นสไลด์หน้าละคลิป |
| `clip demo/*.mp4` | ต้นฉบับที่อัด ไม่ได้แก้ไข |
| `clip demo/edit/` | รายการตัดต่อ `edl-*.json` และตัวเรนเดอร์ `render.py` |

ทุกไฟล์ที่ตัดต่อแล้วเป็น 1920×1080 30fps H.264 ไม่มีเสียง

## ความหมายของกรอบ

- **กรอบน้ำเงิน** ระบบทำงานตามที่ออกแบบ
- **กรอบแดง** ระบบไม่ยอมหรือเตือน ตามกฎใน Activity และ State
- ทุกกรอบค้างบนจออย่างน้อย 4 วินาที พอพูดหนึ่งประโยค
- ช่วงที่ภาพเร็วคือเร่ง 2 เท่า เป็นช่วงกรอกฟอร์ม พูดภาพรวมได้ ไม่ต้องชี้จุด

## ถ้ากรรมการถามถึงส่วนที่ไม่อยู่ในวิดีโอ

วิดีโอตัดส่วนที่เป็นการกรอกฟอร์มออก ถ้ากรรมการถาม ตอบตามนี้

- **หลักสูตร** เพิ่มแผนและเพิ่มรายวิชาเข้าแผนได้ ระบบแสดงเฉพาะวิชาที่ยังไม่อยู่ในแผน
- **ตารางสอน** ตั้งเงื่อนไขของครูได้ เช่นคาบสูงสุดต่อวัน และล็อกเวลากิจกรรมก่อนจัดอัตโนมัติได้
- **เช็คชื่อ** หน้าห้องที่ฉันสอนกรองนักเรียนใกล้ มส และ มส ให้ครูติดตามได้
- **กล่องงาน** ห้องที่ถูกต้องกดอนุมัติได้ ข้อมูลถูกล็อก
- **ออกรายงาน** มีรายงานแยกฉบับ กรองตามปีการศึกษา ภาคเรียน และห้องได้ การส่งออก PDF ยังเป็นต้นแบบ ยังไม่เชื่อมต่อ

## แก้วิดีโอภายหลัง

1. แก้ `clip demo/edit/edl-N.json` รูปแบบไฟล์อยู่ใน `clip demo/edit/EDL-FORMAT.md`
2. เรนเดอร์คลิปแยกใหม่ ใช้เวลาประมาณ 35 วินาที

```bash
cd "clip demo/edit" && python render.py all
```

3. คลิปรวมไม่อัปเดตเอง ต้องต่อไฟล์ใหม่ตามลำดับ 1 ถึง 6 ด้วย ffmpeg concat แบบ `-c copy`

ถ้าอยากดูตัวอย่างเร็ว ๆ ก่อน ใช้ `python render.py all --preview` ได้ไฟล์ 720p ใน `clip demo/edited/preview/`
