# ADR 0005 — คำขอปลดล็อก ต้องให้ฝ่ายวิชาการอนุมัติ

- สถานะ: ยอมรับแล้ว (มาแทนพฤติกรรม “ปลดล็อกทันที” ใน Demo แรก)
- วันที่: 2026-09-30

## บริบท
หลังส่งผลการเรียนหรือได้รับอนุมัติแล้ว ครูอาจต้องแก้ข้อมูลอีก เช่น นักเรียนมาส่งงานเพื่อแก้ ร
ถ้าให้ครูปลดล็อกเองได้ การอนุมัติของฝ่ายวิชาการก็จะไม่มีความหมาย

## การตัดสินใจ
- ครูผู้สอนยื่น **คำขอปลดล็อก** ได้เมื่อห้องอยู่ในสถานะ “รอตรวจ” หรือ “อนุมัติแล้ว” และต้องระบุเหตุผลทุกครั้ง
- ระหว่างรอพิจารณา สถานะเดิมยังคงอยู่ แต่มีป้าย “มีคำขอปลดล็อก”
- ฝ่ายวิชาการ **อนุมัติคำขอ** แล้วสถานะจะกลับเป็น “กำลังบันทึก” ครูต้องส่งผลการเรียนใหม่ หรือ **ปฏิเสธคำขอ** พร้อมเหตุผล แล้วสถานะเดิมยังคงอยู่
- คำขอ ผลการพิจารณา และเหตุผล จะถูกบันทึกในประวัติของห้องเรียนที่สอน

## ผลที่ตามมา
- ฝ่ายวิชาการต้องมีกล่องงานที่รวม “รอตรวจ” และ “คำขอปลดล็อก” ไว้ด้วยกัน
- ถ้าเคยอนุมัติแล้ว ผลอนุมัติครั้งก่อนยังคงอยู่ในประวัติ ไม่ถูกลบ
