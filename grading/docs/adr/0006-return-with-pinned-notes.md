# ADR 0006 — การตีกลับ = เหตุผลรวม + หมุดข้อสังเกตรายช่อง/รายคน

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-30

## บริบท
ถ้าการตีกลับมีแค่ข้อความรวม ครูต้องไล่หาเองว่าช่องไหนผิด โดยเฉพาะในตารางที่มี 36 คน × 8 องค์ประกอบ

## การตัดสินใจ
- การตีกลับต้องมี **เหตุผลรวม** (บังคับกรอก) และมี **หมุดข้อสังเกต** ได้หลายหมุด (ไม่บังคับ)
- หมุดปักได้ 2 ระดับ คือ **รายช่อง** (นักเรียน × องค์ประกอบ) หรือ **รายคน** (ทั้งแถวของนักเรียน)
- ฝ่ายวิชาการปักหมุดได้ในตารางคะแนนแบบอ่านอย่างเดียว ตอนตรวจห้องที่ “รอตรวจ”
- ในหน้ากรอกคะแนน ครูจะเห็นหมุดตรงช่องนั้น และมีรายการหมุดทั้งหมดให้คลิกไปยังช่องได้ ครูกด “แก้แล้ว” ทีละหมุดได้
- เมื่อครูส่งผลการเรียนใหม่ หมุดทั้งหมดของรอบนั้นจะถูกเก็บเข้าประวัติ

## ผลที่ตามมา
- ข้อมูลของห้องเรียนที่สอนต้องมี `reviews[]` (รอบการตรวจ) และแต่ละรอบมี `notes[]` (หมุด)
- ตารางคะแนนต้องแสดงสัญลักษณ์หมุดได้ทั้งในมุมมองครูและมุมมองฝ่ายวิชาการ
