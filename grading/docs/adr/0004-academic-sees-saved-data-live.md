# ADR 0004 — ฝ่ายวิชาการเห็นข้อมูลที่ “บันทึกแล้ว” ได้ทันที ก่อนครูส่งผล

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-30

## บริบท
ฝ่ายวิชาการต้องติดตามความคืบหน้าให้ทันก่อนถึงกำหนดส่ง ไม่ใช่รู้ปัญหาหลังครูส่งผลแล้ว

## การตัดสินใจ
- ฝ่ายวิชาการเห็นทุกอย่างที่อยู่ในสถานะ **บันทึกแล้ว** ของทุกห้องเรียนที่สอน ได้แก่ โครงสร้างคะแนน คะแนนรายช่อง ผลที่คำนวณได้ และประวัติการแก้ไข โดยไม่ต้องรอให้ครูส่งผลการเรียน
- ข้อมูลที่เป็น **ร่าง (ยังไม่บันทึก)** จะไม่มีใครเห็นนอกจากครูผู้สอนคนนั้น
- ห้องที่ยังไม่ส่งผลจะแสดงป้าย “ยังไม่ส่ง — ข้อมูลอาจเปลี่ยนแปลง” เพื่อให้รู้ว่ายังไม่ใช่ผลสุดท้าย

## ผลที่ตามมา
- ครูควรรู้ว่าข้อมูลที่บันทึกแล้วฝ่ายวิชาการมองเห็นได้ ควรแจ้งไว้ในหน้ากรอกคะแนน
- ฝ่ายวิชาการ**ตีกลับได้เฉพาะห้องที่อยู่ในสถานะ “รอตรวจ”** ส่วนห้องที่ยังไม่ส่ง ทำได้แค่ดูอย่างเดียว (รอบนี้ไม่มีการแจ้งเตือน → [ADR 0008](0008-automated-observations-and-bulk-approve.md))
