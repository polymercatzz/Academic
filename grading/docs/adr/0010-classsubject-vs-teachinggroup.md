# ADR 0010 — หน่วยส่งผล: วิชาหลักใช้ `ClassSubject` (วิชา × ห้อง) ชุมนุมใช้ `TeachingGroup` (ผ / มผ)

- สถานะ: ยอมรับแล้ว (แก้สมมติฐานใน er-data-dictionary ฉบับแรก ซึ่งถือว่า `TeachingGroup` = วิชา × ห้อง)
- วันที่: 2026-10-13

## บริบท
ER ฉบับแรกที่ผมออกแบบ ใช้ `TeachingGroup` เป็น “ห้องเรียนที่สอน” แล้วผูกสถานะ รอบการตรวจ และผลการเรียนทั้งหมดไว้กับมัน
แต่ผู้ใช้อธิบายความหมายจริงของ ER เดิมว่า
- `CurriculumSubject` / `ClassSubject` = รายวิชาตามหลักสูตรที่**ต้องเรียน** (พื้นฐานและเพิ่มเติม เรียนทั้งห้อง)
- `TeachingGroup` = กลุ่มแบบ**ชุมนุม** (คละห้อง)

## การตัดสินใจ
1. **`ClassSubject` 1 แถว = รายวิชา × ห้อง × ภาคเรียน** เช่น ค22101 ม.2/1 ภาค 1/2569
   ต้องเพิ่ม `classroom_id` และ `ClassSubject` คือ **ห้องเรียนที่สอน** ที่ใช้บันทึกคะแนน ส่ง และตรวจ ครูผู้สอนอยู่ที่ `ClassSubject.teacher_id` เหมือนเดิม
2. **รายวิชาเพิ่มเติม**เรียนทั้งห้องเหมือนวิชาพื้นฐาน จึงใช้ `ClassSubject` (แยกด้วย `CurriculumSubject.subject_type`)
3. **`TeachingGroup` = ชุมนุม** ผูกกับภาคเรียนและครูที่ปรึกษา (`semester_id`, `advisor_id`) และ**ไม่ผูกกับ `ClassSubject` อีกต่อไป** สมาชิกมาจาก `StudentEnrollment`
4. **ชุมนุมประเมินเป็น ผ / มผ** (ไม่มีโครงสร้างคะแนน ไม่มีเกรด 0–4) ระบบเสนอ มผ ถ้าเวลาเข้าร่วมต่ำกว่าเกณฑ์ แต่**ครูเป็นผู้เลือกผลสุดท้าย**
5. **ชุมนุมใช้ขั้นตอนเดียวกับวิชาหลัก** คือ ส่ง → รอตรวจ → อนุมัติ / ตีกลับ และมีคำขอปลดล็อก (ADR 0002, 0005)
6. ตารางที่ใช้ได้กับทั้งสองหน่วย ได้แก่ `GradeSubmission`, `UnlockRequest`, `GradeChangeLog` ใช้ **FK 2 ตัว (`class_subject_id`, `teaching_group_id`) ที่ NULL ได้ และมี CHECK ให้มีค่าเพียงตัวเดียว**

## ผลที่ตามมา
- โครงสร้างคะแนน (`AssessmentCategory`) ผูกกับ `ClassSubject` จึงเป็น**รายห้อง** ตรงกับ Demo ส่วนความเหมือนกันระหว่างห้องได้จาก `AssessmentCategoryTemplate` ของ `CurriculumSubject`
- นักเรียนของวิชาหลักมาจาก `StudentClassroom` (ทั้งห้อง) ไม่ต้องใช้ `StudentEnrollment`
- ผลการเรียนแยกเป็น 2 ตาราง: `StudentSubjectResult` (วิชาหลัก, เกรด) และ `ActivityResult` (ชุมนุม, ผ/มผ)
- ใน Demo ยังไม่มีชุมนุม ถ้าจะสาธิต ต้องเพิ่มประเภทห้องเรียนที่สอนแบบ ผ/มผ ภายหลัง
- `er-diagram.html` ยังเป็นเวอร์ชันก่อน ADR นี้ ต้องอัปเดตตาม `er-data-dictionary.md`
