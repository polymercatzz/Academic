# ADR 0007 — อนุมัติห้องที่ตัวเองสอนได้ แต่ต้องมีป้าย “ตรวจงานตนเอง”

- สถานะ: ยอมรับแล้ว (ปิดประเด็นที่ค้างไว้ใน ADR 0003)
- วันที่: 2026-09-30

## บริบท
ครูฝ่ายวิชาการอาจเป็นครูผู้สอนของห้องที่ต้องตรวจเอง และโรงเรียนขนาดเล็กมักมีฝ่ายวิชาการเพียงคนเดียว
ถ้าห้ามตรวจงานตัวเอง ห้องนั้นจะไม่มีใครอนุมัติได้เลย

## การตัดสินใจ
- อนุญาตให้ครูฝ่ายวิชาการอนุมัติหรือตีกลับห้องที่ตนเองเป็นครูผู้สอนได้
- การตรวจแบบนี้จะมีป้าย **ตรวจงานตนเอง** แสดงในกล่องงาน ในหน้ายืนยันอนุมัติ ในประวัติ และในรายงานภาพรวม
- ห้องที่ตรวจงานตนเอง **จะไม่ถูกรวมในการอนุมัติหลายห้องพร้อมกัน** ต้องเปิดดูและอนุมัติทีละห้อง ([ADR 0008](0008-automated-observations-and-bulk-approve.md))

## ผลที่ตามมา
- บันทึกการตรวจต้องเก็บทั้งผู้ตรวจและครูผู้สอน เพื่อคำนวณป้ายนี้ได้
