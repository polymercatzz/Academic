# ADR 0013 — เช็คชื่อย้อนหลัง การแก้ ขาด → มา และการปลด มส

- สถานะ: ยอมรับแล้ว (ข้อ 1 รอยืนยันกับผู้ใช้จริง)
- วันที่: 2026-11-05

## บริบท
ผลการรีวิวหน้าเช็คชื่อรายคาบมีประเด็นดังนี้: ครูลืมเช็คชื่อแล้วต้องมาเช็คย้อนหลังโดยจำไม่ได้ว่าใครขาด,
การแก้ ขาด → มา ทำได้ง่ายเกินไปทั้งที่ทำให้เวลาเรียนเพิ่มขึ้น และยังไม่มีทางรองรับนักเรียน มส ที่ผู้บริหารอนุมัติให้มีสิทธิ์สอบ

## การตัดสินใจ
1. **เช็คชื่อย้อนหลัง** — คาบที่เลยวันสอนแล้วแต่ยังไม่เช็ค ครูเลือกข้อมูลเริ่มต้นได้ 3 แบบ แล้วตรวจแก้รายคนก่อนบันทึก
   - อิงคาบก่อนหน้า: คาบล่าสุดก่อนหน้าของห้องเดียวกันในวันนั้นที่เช็คแล้ว
   - อิงคาบเช้า: คาบแรกของวันที่เช็คแล้วของห้องเดียวกัน
   - ให้ทุกคนมา
   คัดลอกเฉพาะ ลา และ ขาด (สายในคาบอื่นไม่ได้แปลว่าสายคาบนี้) และเก็บวิธีที่ใช้ไว้ใน `record.fill` เพื่อให้รู้ว่าเป็นข้อมูลที่เติมย้อนหลัง
   **ยังต้องถามพี่แมน** ว่าโรงเรียนทำอย่างไรจริง และควรมีกรอบเวลาที่เช็คย้อนหลังได้หรือไม่
2. **แก้ ขาด → มา ต้องยืนยันและระบุเหตุผล** (อย่างน้อย 10 ตัวอักษร) — ถามทันทีที่กดเปลี่ยนรายคน ไม่ใช่ตอนบันทึก
   เพราะถ้าแก้หลายคนแล้วถามรวมตอนบันทึก เหตุผลจะปนกันและผู้ใช้จำไม่ได้ว่าแก้ใครไปบ้าง ยกเลิกแล้วสถานะคงเป็น ขาด
   ปุ่ม "ทุกคนมา" ข้ามคนที่บันทึกไว้ว่าขาด แถวที่แก้แล้วไฮไลต์พร้อมเหตุผลจนกว่าจะบันทึก
   การเปลี่ยนแบบอื่น (เช่น ขาด → สาย) ทำได้ตามปกติ ทุกการแก้คาบที่เคยบันทึกแล้วลงประวัติพร้อมผู้แก้ เวลา และเหตุผล (`history.att`, `history.reason`)
   ประวัติของคาบแสดงใต้ตารางเช็คชื่อ และในแท็บประวัติการแก้ไขของระบบบันทึกคะแนน
3. **ปลด มส** — ครูผู้สอนบันทึกได้หลังผู้บริหารอนุมัติแล้ว (นอกระบบ) ต้องเลือกกรณี กรอกเลขที่บันทึกอนุมัติ และเหตุผล (`sec.msWaiver[sid]`)
   - มีเหตุสุดวิสัย ได้รับอนุมัติให้มีสิทธิ์สอบ → ตัดสินผลการเรียนตามปกติ
   - เรียนหรือทำงานชดเชยจนครบเวลาเรียน → ได้ระดับผลการเรียนไม่เกิน 1
   เวลาเรียน (%) ไม่เปลี่ยน (ยังคำนวณจากการเช็คชื่อตาม [ADR 0011](0011-attendance-drives-ms-and-locks-with-submission.md)) แต่สถานะเป็น "ปลด มส แล้ว"
   บันทึกหรือยกเลิกได้เฉพาะห้องที่ยังไม่ส่งผล หลังส่งแล้วต้องขอปลดล็อก ([ADR 0005](0005-unlock-request.md))
4. **ครูประจำชั้นดูรายวิชาย้อนหลัง** — แท็บ "รายวิชา" แสดงนักเรียน × ทุกคาบที่ผ่านมาของวิชาที่เลือก (ดูอย่างเดียว)

## ทางเลือกที่ไม่เลือก
- เติมคาบที่ลืมเช็คให้อัตโนมัติ: เร็ว แต่ข้อมูลไม่ได้ผ่านการตรวจของครู และ มส คิดจากข้อมูลนี้โดยตรง
- ให้ฝ่ายวิชาการอนุมัติการปลด มส ในระบบ: ครบกว่า แต่ยังไม่มีหน้าคำขอสำหรับเรื่องนี้ ใช้เลขที่บันทึกอนุมัติแทนไปก่อน

## ผลที่ตามมา
- `attendance_session` ต้องมี `checked_by` และ `fill_method` และต้องมีตาราง `ms_waiver` ใน ER ([ขอบเขต 4](../../../docs/database/04-attendance.md))
- การแก้ไขการเช็คชื่อเก็บเหตุผลใน `grade_change_log.reason` ([ขอบเขต 2](../../../docs/database/02-grading.md))
