# ADR 0001 — ครูฝ่ายวิชาการดูได้อย่างเดียว และ “ตีกลับ” แทนการแก้คะแนนเอง

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-30

## บริบท
ครูฝ่ายวิชาการต้องตรวจสอบการกรอกคะแนนของครูผู้สอนทุกคน ถ้าเจอข้อผิดพลาด ระบบต้องมีทางให้แก้

เอกสารโครงงาน (UC-12) กำหนดให้ครูผู้สอนเป็นผู้บันทึกและแก้ไขคะแนน และระบบต้องเก็บประวัติการแก้ไข

## ตัวเลือกที่พิจารณา
1. ฝ่ายวิชาการดูได้อย่างเดียว ถ้าเจอปัญหาให้ตีกลับพร้อมเหตุผล
2. ฝ่ายวิชาการแก้คะแนนแทนครูได้ แต่ต้องระบุเหตุผล
3. ดูได้อย่างเดียว และไม่มีกลไกตีกลับในระบบ

## การตัดสินใจ
เลือกข้อ 1 ครูฝ่ายวิชาการ**ไม่มีสิทธิ์แก้ไขคะแนน** โครงสร้างคะแนน หรือผลการประเมินของห้องเรียนที่สอน
ถ้าพบปัญหา ให้ **ตีกลับ** ห้องเรียนนั้นพร้อมเหตุผล ครูผู้สอนเป็นผู้แก้ไข แล้วส่งผลการเรียนใหม่

## ผลที่ตามมา
- ผู้แก้ไขคะแนนมีคนเดียวเสมอ คือครูผู้สอนของห้องนั้น ประวัติการแก้ไขจึงไม่กำกวม
- ถ้าต้องแก้เรื่องเล็กน้อย จะใช้เวลามากกว่าการแก้เอง เพราะต้องตีกลับแล้วรอครูส่งใหม่
- หน้าจอของฝ่ายวิชาการใช้ตารางคะแนนชุดเดียวกับครูได้ แต่ต้องอยู่ในโหมดอ่านอย่างเดียวเสมอ
