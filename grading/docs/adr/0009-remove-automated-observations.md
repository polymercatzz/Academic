# ADR 0009 — นำข้อสังเกตอัตโนมัติออกจากระบบ (ในรอบนี้)

- สถานะ: ยอมรับแล้ว (มาแทนส่วน “ข้อสังเกตอัตโนมัติ” ใน [ADR 0008](0008-automated-observations-and-bulk-approve.md))
- วันที่: 2026-09-30

## บริบท
หลังสร้าง Demo มุมมองฝ่ายวิชาการ ผู้ใช้ขอให้นำข้อสังเกตอัตโนมัติออกในรอบนี้ (4 กฎ: `SAME_SCORE`, `GRADE4_HIGH`, `MEAN_GAP`, `MANY_FLAGGED`)

## การตัดสินใจ
- ระบบ**ไม่คำนวณและไม่แสดง**ข้อสังเกตอัตโนมัติในทุกหน้า ได้แก่ แผงในหน้าตรวจ, จุดแดงในตาราง ห้อง × รายวิชา, ตัวกรอง “เฉพาะที่มีข้อสังเกต”, คอลัมน์ในกล่องงาน, หน้ายืนยันอนุมัติ และคอลัมน์ในรายงาน/CSV
- ฝ่ายวิชาการยังชี้จุดผิดได้ด้วย**หมุดข้อสังเกต** ที่ปักเองตอนตรวจ ([ADR 0006](0006-return-with-pinned-notes.md)) ส่วนนี้ไม่เปลี่ยน
- **เงื่อนไขการอนุมัติหลายห้องพร้อมกัน**เหลือ 3 ข้อ คือ สถานะรอตรวจ · ไม่มีคำขอปลดล็อกค้าง · ไม่ใช่การตรวจงานตนเอง

## ผลที่ตามมา
- ห้องที่อนุมัติพร้อมกันได้มีมากขึ้น เพราะไม่มีตัวกรองจากข้อสังเกตแล้ว ฝ่ายวิชาการต้องเลือกเองว่าห้องไหนควรเปิดดูก่อน
- ข้อมูลจำลองยังมีห้องที่มีข้อมูลแปลก (เช่น ส21101 ม.1/3 ค่าเฉลี่ยต่ำมาก, ท21101 ม.1/1 จิตพิสัยเต็มทั้งห้อง) ไว้สาธิตการตรวจและปักหมุดเอง
- ถ้าจะนำกลับมาในอนาคต ใช้กฎและเกณฑ์ใน ADR 0008 เป็นจุดเริ่มต้นได้ (รวมถึงบทเรียนเรื่องใช้ค่ามัธยฐานใน `MEAN_GAP`)
