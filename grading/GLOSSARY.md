# อภิธานศัพท์ (Ubiquitous Language)

คำที่ใช้ในเอกสาร โค้ด และหน้าจอของระบบบันทึกคะแนน ให้ใช้ความหมายตามนี้เท่านั้น
ถ้ามีคำใดที่ยังไม่ได้ตัดสินใจ จะอยู่ในหัวข้อ “⚠ ยังไม่ชัดเจน”

## บทบาท (Role)

| คำ | ความหมาย | ในโค้ด |
|---|---|---|
| **ครูผู้สอน** | ครูที่ได้รับมอบหมายให้สอนรายวิชาหนึ่งในห้องเรียนหนึ่ง มีหน้าที่ตั้งโครงสร้างคะแนน กรอกคะแนน และส่งผลการเรียนของห้องที่ตนสอน | `TEACHER` |
| **ครูที่ปรึกษาชุมนุม** | ครูที่ดูแลชุมนุม บันทึกผล ผ / มผ และส่งผลของชุมนุม เป็นบทบาทของครูผู้สอนคนเดิม ไม่ใช่บทบาทใหม่ในระบบ | DB: `TeachingGroup.advisor_id` |
| **ครูประจำชั้น** | ครูที่ดูแลห้องเรียนหนึ่ง (เช่น ม.2/1) เห็นการเข้าเรียนของนักเรียนในห้องตนทุกวิชาทุกคาบ เพื่อติดตามนักเรียน **ดูได้อย่างเดียว** แก้สถานะที่ครูผู้สอนเช็คไม่ได้ | — |
| **ครูฝ่ายวิชาการ** | คือบทบาท **admin** ของทั้งระบบ (ดู [docs/actors.md](../docs/actors.md)) · ครูที่ได้รับบทบาทดูแลงานวิชาการ ดูข้อมูลของทุกห้องได้ แต่**แก้ไขไม่ได้** ทำได้แค่ อนุมัติ หรือ ตีกลับ ([ADR 0001](docs/adr/0001-academic-view-only-and-return.md)) | — |
| **มุมมอง** | บทบาทที่ผู้ใช้ใช้งานอยู่ในขณะนั้น คนเดียวมีได้หลายบทบาท และสลับได้ (admin = มุมมองฝ่ายวิชาการ, ครู = มุมมองครูผู้สอน) ([ADR 0003](docs/adr/0003-dual-role-switcher.md)) | — |

## หน่วยของงาน

| คำ | ความหมาย | ในโค้ด |
|---|---|---|
| **รายวิชา** | วิชาตามหลักสูตร ระบุด้วยรหัสวิชา เช่น ค22101 คณิตศาสตร์ 3 มีประเภท (พื้นฐาน/เพิ่มเติม) หน่วยกิต และจำนวนชั่วโมง | `code`, `name` |
| **ห้องเรียนที่สอน** (Section) | รายวิชาหนึ่ง (พื้นฐานหรือเพิ่มเติม) × ห้องเรียนหนึ่ง × ภาคเรียนหนึ่ง เป็นหน่วยที่ใช้บันทึกคะแนนและส่งผลการเรียนของวิชาหลัก เช่น ค22101 ม.2/1 ปี 2569/1 ([ADR 0010](docs/adr/0010-classsubject-vs-teachinggroup.md)) | โค้ด: `section` · DB: `ClassSubject` |
| **ชุมนุม** | กลุ่มกิจกรรมพัฒนาผู้เรียนที่คละห้อง มีครูที่ปรึกษา ประเมินเป็น ผ / มผ ไม่มีโครงสร้างคะแนนและเกรด | DB: `TeachingGroup` |
| **หน่วยส่งผล** | สิ่งที่ส่ง ตรวจ อนุมัติ และขอปลดล็อกได้ มี 2 แบบ คือ ห้องเรียนที่สอน (`ClassSubject`) กับ ชุมนุม (`TeachingGroup`) | — |
| **ภาคเรียน** | ปีการศึกษา + ภาคเรียน เช่น 2569/1 | `term` = `"2569-1"` |

## โครงสร้างคะแนน

| คำ | ความหมาย |
|---|---|
| **โครงสร้างคะแนน** | รายการองค์ประกอบคะแนนของห้องเรียนที่สอน ซึ่งมีสัดส่วนรวมกันต้องเท่ากับ 100% |
| **องค์ประกอบคะแนน** | ชิ้นงานหรือการสอบหนึ่งรายการ มีชื่อ คะแนนเต็ม สัดส่วน (%) หมวด และตัวชี้วัด |
| **หมวดคะแนน** | คะแนนเก็บ / สอบกลางภาค / สอบปลายภาค |
| **คะแนนเต็ม** กับ **สัดส่วน** | คะแนนเต็ม คือคะแนนดิบที่ครูกรอก ส่วนสัดส่วน คือน้ำหนักขององค์ประกอบในคะแนนรวม 100 เช่น ได้ 15 จากเต็ม 20 ในองค์ประกอบที่มีสัดส่วน 10% = 7.5 คะแนน |
| **ตัวชี้วัด** | มาตรฐาน/ตัวชี้วัดของหลักสูตร หรือผลการเรียนรู้ ที่องค์ประกอบคะแนนนั้นวัด |

## ผลการเรียน

| คำ | ความหมาย |
|---|---|
| **ระดับผลการเรียน (เกรด)** | 8 ระดับ ได้แก่ 4, 3.5, 3, 2.5, 2, 1.5, 1, 0 ตัดจากคะแนนรวมที่ปัดเป็นจำนวนเต็มแล้ว |
| **ร** | รอการตัดสิน กรอก `ร` (รอส่งงาน) หรือ `ข` (ขาดสอบ) แทนคะแนน |
| **มส** | ไม่มีสิทธิ์สอบ เพราะเวลาเรียนต่ำกว่า 80% |
| **มีสิทธิ์สอบซ่อม** | ได้ระดับ 0 ถ้าสอบซ่อมได้ 50% ขึ้นไป ระดับจะถูกปรับเป็น 1 |
| **นักเรียนที่ต้องติดตาม** | นักเรียนที่ได้ 0, ร หรือ มส |
| **คุณลักษณะอันพึงประสงค์** | ประเมิน 8 ข้อ ระดับ 0–3 แล้วสรุปจากค่าเฉลี่ยที่ปัดเศษ |
| **อ่าน คิดวิเคราะห์ และเขียน** | ประเมิน 5 ด้าน ระดับ 0–3 แล้วสรุปแบบเดียวกัน |
| **ผ / มผ** | ผลของชุมนุม: ผ่าน / ไม่ผ่าน ระบบเสนอ มผ ถ้าเวลาเข้าร่วมต่ำกว่าเกณฑ์ แต่ครูที่ปรึกษาเป็นผู้เลือกผลสุดท้าย |

## การเข้าเรียน

| คำ | ความหมาย |
|---|---|
| **คาบ** | การสอนหนึ่งครั้งของห้องเรียนที่สอนหนึ่ง ในวันที่หนึ่ง ช่วงเวลาหนึ่ง ตามตารางสอน |
| **เช็คชื่อรายคาบ** | ครูบันทึกสถานะการเข้าเรียนของนักเรียนทุกคนในคาบหนึ่ง |
| **สถานะการเข้าเรียน** | มา / สาย / ลา / ขาด — **มา** และ **สาย** นับเป็นเวลาเรียน ส่วน **ลา** และ **ขาด** ไม่นับ (ลาแยกจากขาดเพื่อให้รู้สาเหตุเท่านั้น) |
| **เวลาเรียน (%)** | จำนวนคาบที่นับเป็นเวลาเรียน ÷ จำนวนคาบที่เช็คชื่อแล้ว ใช้ตัดสิน **มส** โดยคิดจากคาบที่เช็คทั้งภาคเรียน ระบบคำนวณจากการเช็คชื่อรายคาบ ไม่ต้องกรอกเอง |
| **คาบที่ยังไม่เช็ค** | คาบในตารางสอนที่ผ่านไปแล้วแต่ครูผู้สอนยังไม่ได้บันทึกการเช็คชื่อ ไม่นับในเวลาเรียน (%) และไม่ห้ามการส่งผลการเรียน แต่ระบบเตือนก่อนส่ง |
| **วันที่ขาดเรียน** | วันที่นักเรียนถูกเช็ค ขาด อย่างน้อย 1 คาบ นับเป็นวัน ไม่นับเป็นคาบ |
| **ใกล้ มส** | ยังไม่ได้ มส แต่ขาดได้อีกไม่เกิน 2 คาบในรายวิชานั้น |
| **นักเรียนกลุ่มเสี่ยงด้านเวลาเรียน** | นักเรียนที่ **ใกล้ มส** อย่างน้อย 1 วิชา ใช้ในหน้าห้องประจำชั้น นักเรียนที่ได้ **มส** แล้วแม้เพียงวิชาเดียว จะอยู่ในกลุ่ม **มส** อย่างเดียว ไม่นับซ้ำในกลุ่มนี้ (แม้จะใกล้ มส ในวิชาอื่นด้วย) (ไม่ใช่ “นักเรียนที่ต้องติดตาม” ซึ่งหมายถึง 0 / ร / มส ตามผลการเรียน) |
| **ขาดได้อีก** | จำนวนคาบที่นักเรียนยังขาดหรือลาได้ก่อนจะได้ มส คิดจากจำนวนชั่วโมงตามหลักสูตรของรายวิชา ใช้เตือนล่วงหน้า |

## สถานะการบันทึก

| คำ | ความหมาย |
|---|---|
| **ร่าง (ยังไม่บันทึก)** | ค่าที่ครูพิมพ์แล้วแต่ยังไม่ได้กดบันทึก อยู่ในหน่วยความจำของหน้าจอเท่านั้น |
| **บันทึกแล้ว** | ค่าที่กดบันทึกแล้ว และมีรายการในประวัติการแก้ไข |
| **ส่งผลการเรียน** | ครูผู้สอนยืนยันว่าข้อมูลของห้องเรียนที่สอนครบแล้ว ข้อมูลจะถูกล็อก และสถานะเป็น “รอตรวจ” |
| **รอตรวจ** | ส่งแล้ว รอฝ่ายวิชาการตรวจ ([ADR 0002](docs/adr/0002-section-status-lifecycle.md)) |
| **ตีกลับ** | ฝ่ายวิชาการส่งห้องเรียนที่สอนคืนให้ครูแก้ไข ต้องมีเหตุผลเสมอ สถานะจะกลับเป็น “กำลังบันทึก” |
| **อนุมัติแล้ว** | ฝ่ายวิชาการยืนยันผลการเรียน ข้อมูลถูกล็อก |
| **คำขอปลดล็อก** | ครูขอแก้ไขข้อมูลหลังส่งหรือหลังอนุมัติ ต้องมีเหตุผล และฝ่ายวิชาการเป็นผู้อนุมัติหรือปฏิเสธ ([ADR 0005](docs/adr/0005-unlock-request.md)) |
| **หมุดข้อสังเกต** | ข้อความที่ฝ่ายวิชาการปักไว้ที่ช่องคะแนนหรือที่แถวของนักเรียนตอนตีกลับ ([ADR 0006](docs/adr/0006-return-with-pinned-notes.md)) |
| **ตรวจงานตนเอง** | ครูฝ่ายวิชาการตรวจห้องที่ตนเองเป็นครูผู้สอน อนุญาตได้แต่ต้องมีป้ายกำกับ ([ADR 0007](docs/adr/0007-self-review-allowed-with-label.md)) |
| **อนุมัติหลายห้องพร้อมกัน** | อนุมัติได้เฉพาะห้องที่รอตรวจ ไม่มีคำขอปลดล็อกค้าง และไม่ใช่การตรวจงานตนเอง ([ADR 0009](docs/adr/0009-remove-automated-observations.md)) |
| **รอบการตรวจ** | การส่งหนึ่งครั้งกับผลการตรวจหนึ่งครั้ง (อนุมัติหรือตีกลับ) ห้องหนึ่งมีได้หลายรอบ |

## ⚠ ยังไม่ชัดเจน

- **การแจ้งลาโดยครูประจำชั้น** — อยู่นอกขอบเขตของรอบนี้ (ตัดสินใจ 2026-10-14) ตอนนี้ **ลา** เป็นสถานะที่ครูผู้สอนเลือกตอนเช็คชื่อเท่านั้น
- **สอนแทน** — คาบที่ครูผู้สอนไม่อยู่และมีครูอื่นเข้าสอนแทน ยังไม่ตัดสินใจว่าใครเป็นผู้เช็คชื่อ (พักไว้ 2026-10-13)

## คำที่ไม่ใช้

- **ข้อสังเกตอัตโนมัติ** — นำออกจากระบบแล้วในรอบนี้ ([ADR 0009](docs/adr/0009-remove-automated-observations.md)) ให้ใช้ **หมุดข้อสังเกต** ซึ่งเป็นสิ่งที่ฝ่ายวิชาการปักเอง อย่าใช้คำว่า “ข้อสังเกต” เฉย ๆ เพื่อหมายถึงสิ่งที่ระบบสร้าง
- **ฝ่ายทะเบียน** — ให้ใช้คำว่า **ฝ่ายวิชาการ** แทน เป็นบทบาทเดียวกัน ตัดสินใจเมื่อ 2026-09-30 เอกสารโครงงาน UC-15 ถึง 17 ที่ใช้คำว่า “ฝ่ายทะเบียน” ควรแก้ให้ตรงกัน
- **TeachingGroup = ห้องเรียนที่สอน** — ใช้ผิดใน er-data-dictionary ฉบับแรก `TeachingGroup` คือ **ชุมนุม** ส่วนห้องเรียนที่สอนคือ `ClassSubject` ([ADR 0010](docs/adr/0010-classsubject-vs-teachinggroup.md))
- **ข้อมูลที่ฝ่ายวิชาการเห็น** — ต้องระบุว่าเป็นข้อมูลที่ **บันทึกแล้ว** เสมอ ฝ่ายวิชาการไม่เห็นร่าง ([ADR 0004](docs/adr/0004-academic-sees-saved-data-live.md))
