# Demo ระบบบันทึกคะแนน (Mockup)

> ย้ายเข้ามาเป็นส่วนหนึ่งของ Academic Report แล้ว: เปิดผ่าน sidebar กลาง (กลุ่ม “บันทึกคะแนน” / “เช็คชื่อ” ในบทบาทครู และ “ผลการเรียน” ในบทบาท admin) ปุ่มรีเซ็ตและสลับบทบาทอยู่ใน sidebar กลาง

HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไร และไม่ต้องใช้อินเทอร์เน็ต ข้อมูลทั้งหมดเป็นข้อมูลจำลอง

## วิธีเปิด
ดับเบิลคลิก `scores.html` ก็เปิดได้เลย การแก้ไขจะบันทึกไว้ในเบราว์เซอร์เครื่องนั้น (localStorage)
ถ้าต้องการเริ่มใหม่ ให้กด “รีเซ็ตข้อมูล Demo” ที่มุมล่างซ้าย

## โครงสร้างไฟล์
- `scores.html` — โครงหน้า + ไอคอน
- `assets/css/style.css` — ธีมและ layout (รองรับจอมือถือ และสั่งพิมพ์ได้)
- `assets/js/data.js` — ค่าคงที่: ผู้ใช้/บทบาท รายวิชา เกณฑ์เกรด คุณลักษณะฯ ตัวชี้วัด การมอบหมายครู
- `assets/js/seed.js` — สร้างข้อมูลจำลองทั้งโรงเรียน (ม.1–ม.3 × 3 ห้อง × 9 วิชา)
- `assets/js/app.js` — router, การคำนวณผลการเรียน, ตารางกรอกคะแนน, การส่งผล (มุมมองครูผู้สอน)
- `assets/js/academic.js` — มุมมองครูฝ่ายวิชาการ: ภาพรวม กล่องงาน การตรวจ หมุดข้อสังเกต รายงาน
- `attendance.html` + `assets/js/attendance.js` + `assets/css/attendance.css` — หน้าเช็คชื่อรายคาบ (แยกจากหน้าบันทึกคะแนน แต่ใช้ข้อมูลชุดเดียวกัน)
- `assets/js/attendance-core.js` — ตารางสอนจำลอง และการคำนวณเวลาเรียน (%) ใช้ร่วมกันทั้งสองหน้า ([ADR 0011](docs/adr/0011-attendance-drives-ms-and-locks-with-submission.md))
- `docs/` — อภิธานศัพท์ ADR 0001–0011 และ spec ของบทบาทฝ่ายวิชาการ
- `docs/er-data-dictionary.md` + `docs/er-diagram.html` — ER ที่ปรับจากของเดิม และ Data Dictionary (ER ต้องต่ออินเทอร์เน็ตเพื่อโหลด Mermaid)

## ลำดับการสาธิตที่แนะนำ
1. **รายวิชาของฉัน** — การ์ดแต่ละห้องแสดงความคืบหน้า 4 ขั้น สถานะ และจำนวนวันก่อนถึงกำหนดส่ง
2. **ค22101 ม.2/1 → กรอกคะแนน** — พิมพ์คะแนนแล้วกด Enter เพื่อลงไปคนถัดไป ถ้าคะแนนเกินเต็มช่องจะเป็นสีแดง พิมพ์ `r` = ร หรือ `x` = ขาดสอบ
   คัดลอกช่วงคะแนนจาก Excel แล้วกด Ctrl+V วางได้หลายช่องพร้อมกัน กด Ctrl+S เพื่อบันทึก จากนั้นดูได้ในแท็บ “ประวัติการแก้ไข”
3. **ค22201 ม.2/1 → โครงสร้างคะแนน** — ตั้งโครงสร้างจากแม่แบบ ถ้าสัดส่วนรวมไม่ครบ 100% จะบันทึกไม่ได้
4. **ค22101 ม.2/2 (ถูกตีกลับ)** — แถบด้านบนแสดงเหตุผลและหมุดข้อสังเกต กด “ไปที่ช่อง” เพื่อกระโดดไปยังช่องนั้น และกด “แก้แล้ว” ทีละหมุด
   จากนั้นไปที่แท็บ “ผลการเรียน & ส่งผล” แล้วส่งใหม่ สถานะจะเป็น “รอตรวจ” รอบที่ 2
5. **นักเรียนที่ต้องติดตาม** — รวมนักเรียนที่ได้ 0 / ร / มส จากห้องที่ตนสอน

### มุมมองฝ่ายวิชาการ (สลับที่ปุ่มหัวเว็บ)
6. **ภาพรวมทั้งโรงเรียน** — ตาราง ห้อง × รายวิชา สีตามสถานะ มีตัวกรองชั้น/วิชา/สถานะ และแท็บ “รายครู”
7. **กล่องงาน** — กด “เลือกทั้งหมดที่อนุมัติได้” แล้ว “อนุมัติที่เลือก” ส่วนห้องที่เป็นการตรวจงานตนเอง หรือมีคำขอปลดล็อก จะเลือกไม่ได้ (ชี้เมาส์ที่ช่องเลือกเพื่อดูเหตุผล)
   ด้านล่างเป็นคำขอปลดล็อก ให้อนุมัติหรือปฏิเสธ (ปฏิเสธต้องใส่เหตุผล)
8. **ส21101 ม.1/3** — ค่าเฉลี่ยต่ำผิดปกติ ลองเปิดดูผลการเรียน แล้วเปิด “โหมดปักหมุด” คลิกช่องหรือชื่อนักเรียนเพื่อปักหมุด จากนั้นกด “ตีกลับให้แก้ไข”
9. **ค22101 ม.2/3** — ห้องที่ครูสมศรีสอนเอง อนุมัติได้ แต่จะติดป้าย “ตรวจงานตนเอง”
10. **รายงานภาพรวม** — ส่งออก CSV สถานะการส่งของทุกห้อง และนักเรียน 0 / ร / มส ทั้งโรงเรียน

## เทียบกับระบบเดิม
| ระบบเดิม | Demo ใหม่ |
|---|---|
| ตารางรายวิชามีแค่ปุ่ม “บันทึกคะแนน” | การ์ดบอกความคืบหน้า สถานะ และกำหนดส่ง |
| หัวคอลัมน์เป็นตัวหนังสือแนวตั้ง อ่านยาก | หัวคอลัมน์แนวนอน บอกคะแนนเต็มและสัดส่วน % |
| ไม่รู้ว่ากรอกผิดจนกว่าจะกดบันทึก | ตรวจทันทีระหว่างพิมพ์ และมีจุดบอกช่องที่แก้แต่ยังไม่บันทึก |
| ต้องคำนวณเอง หรือดูผลคนละหน้า | คำนวณรวม/เกรด/สถานะสดในแถวเดียวกัน |
| ปุ่มยกเลิก/บันทึก/ส่งผล สีแดงอยู่ใกล้กัน | แถบบันทึกติดด้านล่างจอ ส่วนการส่งผลแยกไปขั้นสุดท้าย พร้อมรายการตรวจสอบก่อนส่ง |

## เช็คชื่อรายคาบ (`attendance.html`)
เปิดจากเมนู “เช็คชื่อรายคาบ” ในระบบบันทึกคะแนน หรือเปิดไฟล์ `attendance.html` โดยตรง ภาคเรียนจำลองตั้งให้วันนี้อยู่ในสัปดาห์ที่ 16

1. **คาบวันนี้** — คาบที่ครูสมศรีสอนวันนี้ตามตารางสอน กด “เช็คชื่อ” แล้วเปลี่ยนเฉพาะคนที่ไม่มา (ตั้งต้นให้ทุกคนมา) เลือกแถวแล้วกด `1`–`4` = มา / สาย / ลา / ขาด
2. **คาบที่ยังไม่เช็ค** — มี 3 คาบที่ลืมเช็ค ระบบบันทึกคะแนนจะเตือนตอนส่งผล (ส่งได้)
3. **ห้องที่ฉันสอน → ค22101 ม.2/1** — เลขที่ 8 เวลาเรียน 71.7% ได้ มส ซึ่งเป็นตัวเลขเดียวกับในหน้าผลการเรียนของระบบบันทึกคะแนน
4. **ห้องประจำชั้น ม.2/1** — ตารางนักเรียน × คาบ ของทุกวิชาในวันหนึ่ง (ดูอย่างเดียว) ในวันเรียนล่าสุดก่อนวันนี้ มีนักเรียนขาดทั้งวัน ระบบแจ้งเตือนไว้ด้านบน
5. **ห้องประจำชั้น → สรุปทั้งภาค** — กล่องสรุป 4 กล่อง (กดเพื่อไฮไลต์ในตาราง) รายชื่อนักเรียน มส และนักเรียนกลุ่มเสี่ยงด้านเวลาเรียน กราฟแนวโน้มรายสัปดาห์ และเวลาเรียนแยกตามวิชา กดชื่อนักเรียนเพื่อเปิดแผงรายละเอียด (เวลาเรียนรายวิชา ปฏิทินวันที่ขาด/ลา)
